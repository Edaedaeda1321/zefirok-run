СЛАДКИЙ ЗАБЕГ — RELEASE 1.3.0 + НОВАЯ КАРТИНКА НОВОСТИ
Дата: 17 октября 2026

ПАТЧ ДЛЯ ДЕЙСТВУЮЩЕГО PRODUCTION-ПРОЕКТА
Это полная версия патча 1.3.0, включающая исправление кнопки почты
и изображение новости, присланное владельцем игры.

СОСТАВ АРХИВА
  index.html                   — версия 1.3.0, окно «Что нового», история релизов
  src/worker.js                — версия/текст новости 1.3.0 и Telegram-бот
  assets/news/news_update_1.3.0.webp — баннер 1672x941 WebP для игры
  assets/news/news_update_1.3.0.jpg  — JPEG-версия для Telegram sendPhoto
  README_RU.txt                — этот файл
  RELEASE_NOTES_1_3_0_RU.txt — текст описания версии
  COMMANDS_MAC_LINUX.txt       — команды распаковки, Git и production-деплоя

ВАЖНЫЕ ОСОБЕННОСТИ
- Раздел «О сезоне» и сезонные изменения только описываются: игровая логика не меняется.
- Баннер 1.3.0 хранится в assets/news/ отдельно от assets/rating/.
  Старый файл assets/rating/season-leaderboard-banner.webp не изменяется.
- Для Telegram (бота) подготовлена отдельная версия JPEG: бот отправляет
  эту картинку как HTTPS URL, в игре показывается исходный WebP.
- Telegram sendPhoto теперь получает абсолютный HTTPS-адрес статического изображения,
  а не неподдерживаемый относительный путь /assets/....
- Выпускаемое ботом сообщение использует тот же WebP, что и окно релиза игры.
- Новый идемпотентный ключ release-1.3.0-news-v2-image обновляет картинку в
  уже созданной новости 1.3.0 без дублирования записи (после штатного запуска
  соответствующего серверного пути).
- Миграции D1 не требуются. ECONOMY_RESET_KEY не менялся. Прогресс сохраняется.
- Production-деплой выполняется только через ./update.sh.

УСТАНОВКА
1. Скачайте sweet_run_1_3_0_patch.zip в папку Downloads.
2. Откройте Терминал в КОРНЕ репозитория zefirok-run и убедитесь,
   что ваши текущие изменения сохранены (git status).
3. Выполните команды из COMMANDS_MAC_LINUX.txt.

ВНИМАНИЕ
Распаковка с -o перезаписывает index.html и src/worker.js. Если там есть
незафиксированные правки после подготовки патча, сначала сохраните/сверьте их.
Не выполняйте команды git push и ./update.sh, если predeploy-проверки не прошли.
Никаких изменений в production из этого архива автоматически не выполнено.
