# Мир Зеффи — посадка объектов на землю v11

## Основание

Патч рассчитан на текущую `main` с **New City Pack v10** (361 запись в `world/assets/manifest.json`).
Ранее v9 использовал `meta.height - meta.anchorY`, но в исходных WebP снизу 10–30 пикселей прозрачного поля. Это давало ложное «касание земли» для парков/цветников/скамеек/фонтанов и иногда неправильное масштабирование. В новом наборе v10 данные уже близки к земле, поэтому нельзя опускать все изображения на произвольную величину.

## Исправлено

- Рендерер `world/renderer.js` считает контакт по **непрозрачным пикселям**, а не по всему прямоугольнику картинки. Границы непрозрачности подготовлены заранее, чтобы iPhone не сканировал пиксели во время игры.
- 304 кадра (большинство готовых/строящихся игровых объектов) получили `groundAlphaBounds`; семь новых зданий, все четыре ракурса, все четыре состояния покрыты.
- Для старого цветочного сквера и игровой площадки видимый размер основания подогнан к **92%** ширины соответствующего участка, без изменения footprint в каталоге и серверных сохранениях.
- Для небольших фонтанов, лавочек и прочего декора корректируется именно видимая точка контакта, **не растягивая сами предметы**.
- Для новых объектов и их строительных стадий сохранена калибровка v10, добавлена лишь небольшая посадка на землю (2.5 условных px в масштабе мира), общая для всех поворотов/стадий.
- Контактная тень стала ближе к краям основания, особенно у крупных построек; не требует тяжёлого Canvas blur/filter.
- Все значения геометрии рендеринга — отдельный визуальный слой; Worker, D1, цены, координаты и покупка земельных участков **не изменены**.

**Предел исправления:** если в самом исходном WebP нарисован высокий декоративный подиум/толстая плита, её нельзя убрать смещением. Участок и контакт с землёй исправлены; для полного удаления нарисованного подиума нужен новый исходный 3D-спрайт.

## Файлы в патче

- `world/renderer.js` — вычисление визуального положения, мягкий контакт с грунтом.
- `world/assets/manifest.json`, `world/sprite-manifest.js` — предварительно рассчитанные пиксельные границы всех спрайтов.
- `world/tests/ground-contact-v9.test.mjs` — обновлены проверки предыдущего подхода.
- `world/tests/ground-docking-v11.test.mjs` — 112 новых кадров, все повороты, размеры, совместимость сохранений.
- `scripts/rebuild-world-ground-alpha-v11.py` — необязательная команда для *будущей замены WebP*, запускается разработчиком ассетов, требует Pillow.
- `README_MIR_ZEFFI_GROUND_ALIGNMENT_v11_RU.md` — этот документ.

## Установка в корне `zefirok-run`

Сначала сохраните/закоммитьте свои локальные изменения в Git. Затем:

```bash
git status
git switch main
git pull --ff-only origin main

unzip -o "$HOME/Downloads/Mir_Zeffi_Ground_Alignment_v11_patch.zip" -d .

node --check world/renderer.js
node --check world/sprite-manifest.js
node --test world/tests/*.test.mjs
node --experimental-sqlite scripts/check-zeffi-world-integration.mjs
node scripts/check-world-new-city-pack.mjs
node scripts/check-world-api-wiring.mjs
node scripts/check-world-integration.mjs  # только если локально есть world-preview.html

git diff --check
git add world/renderer.js world/assets/manifest.json world/sprite-manifest.js \
  world/tests/ground-contact-v9.test.mjs world/tests/ground-docking-v11.test.mjs \
  scripts/rebuild-world-ground-alpha-v11.py README_MIR_ZEFFI_GROUND_ALIGNMENT_v11_RU.md
git diff --cached --check
git commit -m "fix(world): ground sprite bases using opaque WebP bounds"
git push origin main
./update.sh
```

**Важно:** `check-world-integration.mjs` требует отдельно сгенерированный `world-preview.html`, который не входит в этот компактный патч и может отсутствовать после чистого `git clone`. Если его нет, пропустите только эту необязательную проверку; остальные тесты должны пройти.

**Не публикуйте при ошибке обязательных тестов.** `./update.sh` выполняется только после успешного `git push origin main`. Прямой `npx wrangler deploy` не нужен.

## Автономная проверка

Отдельно предоставлен `Mir_Zeffi_Ground_Alignment_v11_OFFLINE.html` (не входит в production ZIP). Это полностью автономная игра, в которой обновлены рендерер и манифест. Откройте HTML в браузере (например, Safari/Chrome на Mac); он имеет тестовый кошелёк и не влияет на реальный профиль.

В браузере сравните: старый цветочный сквер, детскую площадку, фонтан, лавочку, автобусный вокзал, автобусную остановку, пруд и ботанический сад. Проверьте 4 поворота и 3 стадии каждого нового объекта, размещение у дороги и у края земли. На устройстве Telegram проведите отдельный smoke-test; локальный Chromium не заменяет iOS WebView.

### При замене игровых WebP в будущем

Перегенерируйте границы после добавления/замены спрайтов (Python/Pillow в рабочем окружении автора артов):

```bash
python3 scripts/rebuild-world-ground-alpha-v11.py
node --test world/tests/ground-docking-v11.test.mjs
```

Не запускайте скрипт на прод-сервере: данные должны быть подготовлены до сборки и сохранены в Git.
