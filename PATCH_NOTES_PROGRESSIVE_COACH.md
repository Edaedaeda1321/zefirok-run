# Progressive Coach — contextual onboarding

Base: current `main` after commit `02a484dad9dd4a4e786b97f16cb413ef1b671dca` (`Add interactive gameplay tutorial`).

## Что меняется

Добавлена единая progressive-onboarding логика: длинные гайды остаются справочником, а автоматические подсказки показываются прямо на реальном интерфейсе только в момент, когда механика становится актуальной.

Автоматические coach marks добавлены только для:
- Магазина: фильтры -> актуальная цена; отдельно один раз объясняется цена в реальном окне подтверждения покупки.
- «Моих покупок» / усилителей: переход во вкладку, правило «1 Бонус награды + 1 Помощник в забеге», затем подсветка кнопки активации без принудительного расходования предмета.
- Первого обычного кейса: переход в «Кейсы» -> реальный клик по изображению для просмотра состава и шансов. Coach никогда сам не нажимает «Открыть» и не расходует кейс.
- Профиля: уровень/XP -> «Мой стиль».
- Сезонного пропуска: прогресс XP -> реальная вкладка «Задания» -> блок состояния заданий.
- Рейтинга: одна подсказка на реальной карточке игрока; завершается реальным открытием мини-профиля.

По требованию проекта автоматические coach marks НЕ добавлялись в:
- Достижения
- Альбом
- Почту
- Друзья
- Ежедневную активность

## Антиспам

- Не более одного нового автоматического coach-flow за одну сессию приложения.
- Каждый flow автоматически показывается только один раз и хранит seen-state в `zefirok_context_coach_seen_v1`.
- Общий session limiter: `zefirok_context_coach_session_v1`.
- Пока не завершено интерактивное обучение самому забегу, остальные автоматические coach marks не запускаются.
- `Пропустить` завершает конкретный flow и больше не показывает его автоматически.
- Подробные существующие гайды через `?` / «Настройки и обучение» сохранены.

## Замена старых автогайдов

- Автоматический длинный профиль/кейс tutorial больше не всплывает при входе в профиль. Ручной подробный гид сохранён.
- Первый вход в рейтинг больше не перехватывается старым длинным tutorial: рейтинг открывается сразу, а внутри показывается короткая контекстная подсказка.

## Безопасность действий

Coach marks не выполняют покупки, не активируют усилители и не открывают кейсы автоматически. Там, где нужен реальный клик, разрешено только безопасное действие: смена вкладки/фильтра или просмотр информации. Экономика и server-authoritative backend не изменены.
