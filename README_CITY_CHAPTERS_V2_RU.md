# «Сладкий Забег» / «Мир Зеффи»: Книга развития города V2

Патч от 16.10.2026. Только UI/UX — без изменения D1, сервера, балансов, строительства и наград.
Основа: свежий GitHub `Edaedaeda1321/zefirok-run` `main`, проверенный перед подготовкой патча.

## Что меняется

- Пять глав оформлены как премиальный игровой альбом. По умолчанию полностью раскрыта только текущая глава; завершённые и будущие компактны.
- Прогресс главы — пять сегментов и счётчик завершённых глав; условия — отдельные крупные карточки с прогресс-барами, изолированными цифрами и цветом готовности.
- Показывается изображение **настоящего декоративного предмета-награды**, строго из уже существующего `WORLD_REWARD_DECOR_BY_ID`. Пользовательский URL с сервера не используется.
- Эмодзи в интерфейсе глав удалены; вместо них используются только настоящие WebP из `assets/mir_zeffi/`, включая `icon_house`, `icon_parks`, `icon_zavedenia`, `icon_all_stroika`, `icon_landshaft`, `icon_decor`.
- Неактивные главы можно раскрывать для просмотра условий, но кнопка получения награды доступна лишь при серверном `canClaim`.
- При получении награды автоматически открывается следующая глава. При обновлении прогресса сохраняется выбранная пользователем глава.
- Устранена причина вида «всё просто текстом» в production: `world.html` ранее не подключал `city-chapters.css`. CSS также подстрахован однократным подключением внутри модуля.
- Мобильная адаптация, читаемые числа, управление клавиатурой/экранными читалками и `prefers-reduced-motion`.

**Нет** новых D1-запросов, таймеров, локальных начислений, нового каталога, миграций или WebP-файлов. Все награды по-прежнему выдаёт Worker.

## Файлы в архиве

1. `world/city-chapters-ui.js` — новый UI-компонент с прежним API `mountCityChapters(...).update(...)`.
2. `world/city-chapters.css` — оформление «Книги развития».
3. `world/tests/city-chapters-ui-v2.test.mjs` — автономные регрессионные тесты на Node.
4. `scripts/apply-city-chapters-v2.mjs` — однократное безопасное подключение CSS/новой версии модуля к существующим страницам.
5. `README_CITY_CHAPTERS_V2_RU.md` — эта инструкция.

## Установка на актуальный проект

Открыть терминал в корне `zefirok-run`, убедиться, что нет посторонних правок в целевых файлах:

```bash
git status --short
git pull --ff-only origin main

git hash-object world/city-chapters-ui.js
git hash-object world/city-chapters.css
```

В исходном `main` на момент подготовки:
- `world/city-chapters-ui.js`: `f439ad8929324c615828f78e7a7afc8546f3fed3`
- `world/city-chapters.css`: `fa838bc48943b9709a1cccfe395f87c09ca101cf`

**Если эти SHA не совпадают и в целевых файлах есть свежие изменения, остановиться и сверить патч:** не перезаписывать более новые редакции.

```bash
unzip -o ~/Downloads/Sladkiy_Zabeg_City_Chapters_Redesign_V2_2026-10-16.zip -d .
node scripts/apply-city-chapters-v2.mjs
node --check world/city-chapters-ui.js
node --test world/tests/city-chapters-ui-v2.test.mjs
npm run check:fast
git diff --check
```

Установочный скрипт меняет **только три текстовые ссылки** в `world.html`, `world/index.html`, `world/app.js` (CSS и query-параметр версии модуля). Он идемпотентен и сначала проверяет все три файла; при несовместимой редакции останавливается, не изменяя частично проект.

После успешных проверок:

```bash
git add world/city-chapters-ui.js world/city-chapters.css world/tests/city-chapters-ui-v2.test.mjs scripts/apply-city-chapters-v2.mjs world.html world/index.html world/app.js
git diff --cached --stat
git commit -m "Redesign Zeffi city chapters with existing icon art"
git push origin main
./update.sh
```

**Не использовать `git add -A`**, поскольку в дереве могут оставаться сторонние локальные README/патчи. Не использовать прямой `npx wrangler deploy`: по проектному регламенту применяется `./update.sh`.

## Тестирование

- `node --check` — синтаксис JS.
- 3 Node-теста: одна активная глава, компактные будущие, разворот, переключение при серверном `claimed`, отсутствие повторного клика, показ только достоверной серверной награды, отсутствие эмодзи.
- Мобильный Chromium QA с реальными существующими ассетами на 320/390/430 CSS px: ошибок JS и горизонтального переполнения нет, 5 глав, одна раскрытая, все иконки загружены.
- Скрипт установки дважды подряд: второй запуск не изменяет файлы.
- Полный production gate на **чистом свежем `main`** и реальный Telegram WebView необходимо проверить на машине разработчика по указанным командам. Production D1 не трогалась.

## Проверить на iPhone после деплоя

Открой личный город -> «Город в цифрах» -> «Книга развития».
Убедись, что карточки не сливаются в текст, первая глава раскрыта, остальные компактны, цели/цифры не пересекаются, предмет награды виден и закрытые главы не позволяют получать награду. При наличии готовой награды проверь на тестовом аккаунте однократную выдачу.
