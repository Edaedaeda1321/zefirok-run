Fix: Конструктор забега остаётся на заглушке «Открой раздел...»

Причина:
Season Pass может заранее загрузить Runner Builder через loadRunnerBuilder(false). Данные уже оказываются в state.runnerBuilder, но сам раздел ещё не был отрисован. При последующем открытии вкладки loadViewCore видел готовый state.runnerBuilder и пропускал loadRunnerBuilder(true), поэтому оставалась исходная заглушка.

Исправление:
- при открытии runnerbuilder, если данные уже загружены, вызывается renderRunnerBuilder();
- если API загрузки реально падает, вместо вечной заглушки выводится текст ошибки и кнопка «Повторить».
