# Сладкий Забег — Season 2 UI Hotfix v4

Кумулятивный патч поверх актуальной сборки `Game.zip`. Включает исправления v1–v3 и новую жёсткую правку горизонтальной дорожки наград.

## v4 — полностью убран iOS/WebView native horizontal overscroll

Повторный тест показал, что предыдущий clamp `scrollLeft` не решал первопричину на iOS/Telegram WebView: нативный `overflow-x:auto` умеет визуально rubber-band'ить контент за пределы `scrollWidth`, даже когда само значение `scrollLeft` уже зажато. Из-за этого пользователь всё ещё мог вытянуть дорожку в большую пустую область.

Теперь:
- у `rewardScroll` отключён нативный горизонтальный overflow (`overflow-x:hidden`);
- горизонтальный drag пальцем обрабатывается вручную;
- при каждом горизонтальном `touchmove` вычисляется новый `scrollLeft` и сразу ограничивается диапазоном `0..scrollWidth-clientWidth`;
- iOS/WebView больше не получает горизонтальный pan, поэтому физически не может показать rubber-band за реальным концом дорожки;
- вертикальный свайп страницы сохранён (`touch-action:pan-y`);
- быстрый переход по slider и программный `scrollToLevel()` продолжают работать, потому что `overflow:hidden` остаётся программно прокручиваемым контейнером.
