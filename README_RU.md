# «Сладкий Забег» — изображения декора и «Дворец воспоминаний»

**Источник:** текущий main `Edaedaeda1321/zefirok-run` (включая ранее установленный патч декора/глав и исправление `ru.js`). `Game(3).zip` не использовался как замена более свежего кода. 

## Что изменено

1. **CC / Сезонный пропуск / сезонные кейсы:** подключены 16 превью объектов класса `decor`. Десять фотографических иллюстраций декора взяты из уже готовых PNG пользователя и *только уменьшены и перекодированы* в RGBA WebP 360x360 для мобильной загрузки. Шесть оставшихся видов ссылаются на реальные существующие спрайты Мира Зеффи. Списки, серверная проверка `world_decor` и ограничения категории `decor` сохранены.
2. **Общий город:** добавлен «Дворец воспоминаний» на новой свободной территории (x=22,y=5), 6x6 клеток. Доступен с первой сюжетной главы (в тестовом закрытом World). 10 отдельный состояний WebP из архива автора: 9 строительных и финальное. Исходные файлы дворца НЕ модифицированы и не перерисованы. Старый пустой/заблокированный участок «Тайна» перенесён на свободный край карты; сюжетная прогрессия не переписана.
3. **Сервер D1:** новый независимый флаг `contributions_enabled=0` с SQL CHECK (не может переключиться в 1). Дворец отсутствует в allowlist настоящих проектов взносов `garden`,`festival`, поэтому API взносов не способен списать деньги по дворцу. Дворец НЕ добавлен в таблицу обычных фондов.
4. **CC / Мир Зеффи / Общие проекты:** управление этапами 1→2→...→10 владельцем, только вперёд, с аудитом, ревизиями, идемпотентным requestId. Операция проходит существующие owner-auth и staging-предохранители Worker. Статус дворца работает даже при отказе старого API общего фонда.
5. **Личный город:** уникальная для игрока постройка `palace-of-memories` в каталоге площадей. Открывается с **10-го уровня города**, цена по умолчанию **280 000 очков и 500 зефира**, стройка **24 часа**, 6x6 клеток, один экземпляр даже при хранении на складе. Ускорение кофе отключено **на клиенте и на сервере**; реальное время/кошельки контролирует Worker, не клиент.
6. Совместимость: существующие опубликованные P1-конфигурации городского баланса без нового ID дополняются сервером безопасной базовой записью, уже купленные объекты и валюта не меняются. Новые изображения дворца доступны для отрисовки по стадиям и в клиентском каталоге. Запись новых D1-таблиц выполняется только миграцией `0124`.

## Порядок установки (ИЗ КОРНЯ РЕПОЗИТОРИЯ)

```bash
git status
git branch --show-current
git pull --ff-only origin main
unzip -o ~/Downloads/Sladkiy_Zabeg_Decor_Art_Palace_Memories_Patch_2026-10-16.zip -d .
git diff --check
npm run check:fast
node --no-warnings --experimental-sqlite --test world/tests/palace-memories-v1.test.mjs
# Перед деплоем применить миграцию в той же основной D1, что и Worker:
npx --yes wrangler@4.131.1 d1 migrations apply zefirok-rewards --remote
# После проверки успешного применения:
git status
git add -A
git commit -m "Add Palace of Memories stages and decor reward artwork"
git push origin main
./update.sh
# После деплоя:
npx --yes wrangler@4.131.1 d1 migrations list zefirok-rewards --remote
git status
```

Команды `npx wrangler deploy` напрямую **не нужны**: production через `./update.sh`.

**ОСТОРОЖНО:** если `git status` показывает несвязанные локальные изменения, не применяйте `git add -A` автоматически; сначала изучите изменения. Не включайте для всех игроков режим Мира Зеффи и новую раздачу декора без теста на авторизованном аккаунте.

### Порядок QA на тестовом игроке

1. В CC откройте награду элитного пропуска и сезонный кейс — у 16 декораций должно быть изображение предмета, а не одинаковый подарок. Подтвердите, что редактирование не допускает здания, парки, дороги.
2. В CC → Мир Зеффи → Общие проекты: «Дворец воспоминаний» = 1/10, надпись «взносы отключены». Переключите **один** этап с причиной, убедитесь что он стал 2/10 и аудит заполнен. Не переходите к 10 без арт-проверки.
3. В общем городе на x22..27,y5..10 должен появиться дворец на актуальной стадии, без кнопки «Внести очки». Обновите и проверьте соответствие CC. Сохранность общего фонда Сада встреч / Фестиваля проверяйте отдельно.
4. В личном городе на 9-м уровне покупка недоступна, на 10-м — доступна за 280 000 очков и 500 зефира (если баланс города не был явно опубликован с другой ценой). Начало списывает валюты **ровно один раз**. Таймер идёт 24 часа и повторная покупка невозможна; ускорение недоступно.
5. Проверьте с настоящего iPhone Telegram вид дворца на участке 6x6 и посадку 10 спрайтов: исходный архив обозначен как `review`, его размеры и опорная точка не гарантировали production-калибровку. При визуальном несоответствии не открывайте режим массово — правится только scale/anchor рендера.
