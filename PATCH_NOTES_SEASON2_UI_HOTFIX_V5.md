# Сладкий Забег — Season 2 UI Hotfix v5

Кумулятивный патч. Содержит все предыдущие исправления v1–v4 и новые исправления этого прохода.

## 1. Лента наград Battle Pass — переписана с нуля

- Удалён нативный горизонтальный scroll ленты на iOS/Telegram WebView.
- Удалена предыдущая v4-логика ручного изменения `scrollLeft`.
- Лента теперь двигается через ограниченный `translate3d` внутри `overflow:hidden` viewport.
- Границы вычисляются только по реальной ширине `rewardTrack`; положение всегда жёстко зажимается между первым и последним уровнем.
- За последним уровнем физически нельзя показать пустое пространство: transform не может выйти за рассчитанную границу.
- Добавлена плавная инерция свайпа и мягкая доводка к ближайшему уровню.
- Вертикальный скролл страницы сохраняется.
- Быстрый переход и range-slider работают через тот же новый механизм.

## 2. Окно активации тарифа — картинки из Control Center

Окно «Элитный / Элитный+ активирован» теперь использует те же LiveOps visual-поля сезона, которые настраиваются в Control Center:

- premium line → `elitePremiumRewardsIcon`
- premium tasks → `elitePremiumTasksIcon`
- rating badge → `eliteRatingBadgeIcon` / `elitePlusRatingBadgeIcon`
- final case → `eliteFinalCaseIcon`
- Elite+ includes Elite → `elitePlusIncludesEliteIcon`
- XP boost → `elitePlusXpBoostIcon`
- bonus levels → `elitePlusLevelsIcon`

Исправление сделано и на серверной стороне notice payload, и на клиентской стороне рендера, поэтому старое ещё не просмотренное уведомление тоже использует актуальные картинки сезона.

## 3. «Получить все доступные награды» — устранён ложный timeout

Старая проблема: клиент отменял bulk-request через 7 секунд, Worker успевал завершить выдачу, UI показывал ошибку, а после перезахода награды уже были получены.

Теперь:

- bulk-операции дают серверу до 22 секунд на штатное завершение;
- если сетевой запрос всё же завершился неопределённо, клиент НЕ сообщает сразу об ошибке;
- выполняется повторная authoritative-проверка `/api/battle-pass/state`;
- если сервер уже зафиксировал награды, UI сразу синхронизирует полученные уровни, показывает успешное получение и summary;
- повторный клик остаётся безопасным: серверная выдача наград уже idempotent и не начисляет их дважды;
- при реально неопределённом результате текст больше не утверждает, что выдача провалилась.
