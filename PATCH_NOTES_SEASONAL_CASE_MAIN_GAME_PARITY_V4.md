# Seasonal Case Main-Game Parity + Tutorial v4

База: актуальный `battle-pass.html` из `main` (Git blob `fea79a86e5062094c18a4a248df380093e2e6018`).

## Что изменено

- Результат открытия сезонного кейса больше не использует упрощённый Battle Pass reward-summary.
- После серверного подтверждения запускается flow обычных кейсов: подготовка -> анимация открытия -> reveal конкретной награды -> следующие награды -> продолжить / открыть ещё.
- Геометрия, лучи, частицы, появление награды, credited-state и две нижние кнопки перенесены из основного case experience и адаптированы под сезон.
- В сезонном варианте используется фон `Ночь сладких чудес`, закрытая/открытая картинка конкретного сезонного кейса и подпись источника.
- Серверная идемпотентность `requestId`, recovery/status-проверка и защита от повторного списания не изменены.
- Карточка сезонного кейса пересобрана: белая нейтральная карточка, иконка слева, название/сезон/количество, отдельное действие `Содержимое и шансы`, отдельная кнопка `Открыть кейс`. Старое золотое выделение info-зоны перекрыто.
- В интерактивное обучение Season Pass добавлен UI-only фейковый сезонный кейс. Он появляется только на учебном шаге, подсвечивается целиком и открывает демонстрационное `Содержимое и шансы`.
- Учебный кейс не вызывает API, не расходует кейсы и не выдаёт награды. После просмотра шага он удаляется из интерфейса.
- Учтены `zefir` и legacy-kind `treats` при показе результата.
