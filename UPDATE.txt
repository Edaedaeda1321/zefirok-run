CASES UX 2.0

- Сортировка переключается: Редкость ↓ / Количество ↓.
- Редкость: Обычный / Серебряный / Золотой / Мифический / Легендарный / Особый (Алекс).
- На карточках складских кейсов компактный счётчик ×N.
- Новые полученные кейсы подсвечиваются и попадают в фильтр «Новые».
- После просмотра/открытия отметка «Новое» снимается.
- Если количество кейса обнулилось, tracking сбрасывается; новое получение снова считается новым.
- Существующий flow «Открыть ещё · N» сохранён: модалку между открытиями закрывать не нужно.
- Пустые состояния адаптированы под фильтры.

PERFORMANCE CANDIDATE
Цель: определить и сократить критический путь grant_home / adm_home.

Оптимизации:
- grant_home: очистка workflow, answerCallback и Telegram-отрисовка запускаются параллельно вместо последовательного ожидания.
- adm_home: support cleanup и проверка доступа выполняются параллельно.
- staff access: короткий 5-секундный memory-cache, ограниченный фактическим временем жизни staff-сессии.

- admin overview: memory cache -> D1 snapshot -> rebuild; повторное открытие не должно пересчитывать агрегаты без необходимости.

3. В Control Center -> Система -> Мониторинг посмотреть новые phase-area строки.
