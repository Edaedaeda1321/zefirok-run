FIX 1.0.9 / LOCAL 2.2 — Case Reliability + Telegram Touch/Back + Overlay Layout

Исправлено в Production:
- восстановлена отсутствовавшая константа CASE_OPEN_REQUEST_TIMEOUT_MS: из-за неё открытие кейсов могло падать после запуска превью;
- открытие подарочных/складских кейсов теперь получает уникальный requestId;
- Worker делает открытие idempotent по requestId: повторный запрос не открывает второй кейс и умеет вернуть уже завершённый результат;
- если первый запрос на мобильной сети завис/оборвался, клиент не закрывает рулетку сразу, а до 45 секунд безопасно опрашивает тот же requestId;
- если сервер уже начислил награду, но ответ потерялся, результат восстанавливается из granted_cases.rewards_json;
- после успешного DB batch физический stock больше не освобождается из-за ошибки только на этапе формирования ответа;
- окно кейса ограничено реальной высотой viewport, длинный список наград прокручивается внутри и больше не растягивает модалку за экран;
- на низких экранах арт кейса и заголовок становятся компактнее;
- окно новостей получает отдельный iOS touch-scroll и реальную высоту Telegram viewport.
