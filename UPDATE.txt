Сладкий Забег 1.0.8 — Story Visual: кофе
Дата: 2026-08-17

Что изменено
1. Сюжетные действия мини-игры теперь поддерживают два независимых объекта:
   - treats — зефир;
   - coffee — кофе.

2. Control Center → Сезонный пропуск → Сюжет → «После открытия главы»:
   - добавлен пункт «Мини-игра · изменить визуал кофе»;
   - для кофе доступны те же операции «Заменить изображение» и «Вернуть обычный визуал»;
   - picker кофе показывает только сезонные изображения из:
     /assets/seasons/<season-id>/minigame/coffee/
   - существующий picker зефира остаётся в:
     /assets/seasons/<season-id>/minigame/currency/
   - preview, диагностика resolver и отметка «Используется» работают для обоих типов.

3. Backend / Story Actions:
   - minigame_visual принимает target=treats и target=coffee;
   - один target нельзя продублировать дважды в одной главе;
   - разные targets разрешены и рассчитываются независимо;
   - seasonId по-прежнему обязан совпадать с сезоном главы;
   - Readiness / Release Gate проверяет картинки и зефира, и кофе.

4. Production resolver:
   - сервер возвращает miniGameVisuals = { treats, coffee };
   - старый miniGameVisual сохранён как совместимый alias для treats;
   - активный визуал каждого объекта вычисляется отдельно по реально открытым главам игрока;
   - reset кофе не сбрасывает зефир, reset зефира не сбрасывает кофе;
   - изменения уже пройденных глав продолжают работать по политике live_story_source.

5. Мини-игра:
   - зефир меняет assets.marshmallow;
   - кофе меняет assets.coffeePickup;
   - спавн, коллизии, количество и начисление валют не изменены;
   - изображение сначала полностью загружается и decode() проходит успешно, только затем применяется;
   - при ошибке загрузки/декодирования конкретный объект остаётся стандартным;
   - одноразовое сюжетное пояснение теперь умеет корректно называть и зефир, и кофе.

6. Battle Pass:
   - после первого открытия главы отправляет в основную игру сразу bundle visual-эффектов;
   - визуал кофе может измениться сразу после сюжетной главы без перезапуска игры.

7. Test Project:
   - блок Story Visual показывает отдельный preview зефира и кофе;
   - показывает текущий источник resolver для каждого объекта;
   - timeline отображает set/reset для обоих targets;
   - при запуске настоящей sandbox-игры применяются оба визуала одновременно;
   - cache-bust обновлён до tp-5.2.4, видимая версия остаётся TP 5.2.
