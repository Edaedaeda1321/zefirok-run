Сладкий Забег 1.0.8 — hotfix сезонных папок Story Visual
Дата: 17.08.2026

Исправлено:
- CC больше не использует внутренний runtime season_id как основное имя папки сезонных visual-assets.
- Каноническая папка определяется как s1 / s2 / s3 / ... по номеру сезона.
- Если номер явно указан в названии сезона (например «Сезон 3»), используется он.
- Если номер в названии не указан, используется хронологический номер сезона по startsAt.
- Для текущего третьего сезона picker теперь ищет:
  /assets/seasons/s3/minigame/currency/
  /assets/seasons/s3/minigame/coffee/
- Старые пути вида /assets/seasons/<runtime-season-id>/... остаются доступными как legacy и не ломаются.
- Фикс применяется одновременно к зефиру и кофе.
- Проверка «путь вне папки сезона» теперь принимает и канонический, и legacy-путь.
- Manifest не менялся: assets/images-manifest.json по-прежнему создаётся штатным custom build при npx wrangler deploy.

Не изменено:
- src/worker.js
- index.html
- test-project.html
- battle-pass.html
- resolver сюжетных визуалов
- экономика, баланс, спавн и коллизии мини-игры
- Staging / Monitoring / рейтинг / профиль

Проверки:
- owner.html inline JavaScript: PASS
- DOM IDs: PASS, дублей нет
- mapping runtime season id -> s3: PASS
- fallback по хронологии -> s3: PASS
- picker находит /assets/seasons/s3/minigame/currency/*.png: PASS
- canonical + legacy roots: PASS
- coffee path /assets/seasons/s3/minigame/coffee/: PASS

Миграция D1 не нужна.
Деплой: npx wrangler deploy
