Сладкий Забег 1.0.9 — FIX Test Project 5.3

Что исправлено
1. Жёсткая изоляция Test Project
- Текущая игровая сборка запускается с test_project=1 и использует только виртуального игрока TP.
- localStorage и sessionStorage игры изолированы отдельным префиксом TP 5.3.
- Telegram CloudStorage в Test Project отключён.
- Игровые /api/* запросы в TP идут только через owner-only sandbox proxy.
- Прямые owner API из игрового iframe, XHR к /api/* и sendBeacon к /api/* блокируются.
- Неизвестный/неподдерживаемый игровой API fail-closed: Production не используется как fallback.
- Внутрь игры передаётся виртуальный профиль tp-player, а не реальный игровой Telegram-профиль владельца.

2. Источник виртуального игрока
- В Test Project явно показывается режим: ИЗОЛИРОВАН или КЛОН · TP ONLY.
- Клон Production является только снимком данных в TP и не работает с реальным аккаунтом.
- Добавлена кнопка «Новый изолированный игрок», которая отвязывает Production-клон и создаёт чистого виртуального игрока.
- Очистка sandbox cache теперь чистит TP localStorage и TP sessionStorage, не затрагивая Production-хранилище.

3. Case Lab
- Добавлен Кейс Алекса в полный список тестовых кейсов.
- Можно выдать выбранный кейс: ×1 / ×5 / ×10 / ×25.
- Можно одной кнопкой выдать все типы кейсов.
- Можно покупать и открывать кейсы на виртуальном тестовом балансе.
- Алекс-кейс использует настоящую текущую механику коллекции, дублей и награды за 4/4.

4. Принудительный дроп Кейса Алекса
Можно выбрать следующий результат:
- Алекс · скин
- След Алекса
- Рамка Алекса I
- Рамка Алекса II
- Аватар Алекса I
- Аватар Алекса II
- случайный результат

Опция «Считать предмет новым» временно удаляет выбранный предмет только у виртуального игрока TP, чтобы проверить jackpot-анимацию первого получения.
Если опцию выключить и предмет уже есть, можно проверить реальную компенсацию за дубль (+10 000 очков).

Кнопка «Проверить анимацию в игре»:
- добавляет 1 Кейс Алекса виртуальному игроку;
- фиксирует выбранный следующий дроп;
- запускает текущую игру в Sandbox;
- открывает «Мои покупки → Кейсы»;
- автоматически открывает Кейс Алекса после появления карточки на складе;
- проигрывается настоящая игровая анимация открытия и выбранной награды.

5. Коллекция Алекса в TP
- TP зеркалирует 4 слота: Алекс / След / любая Рамка / любая Аватарка.
- При первом 4/4 виртуальному игроку добавляется Золотой кейс.
- Награда за 4/4 в TP не затрагивает Production.

6. Control Center
- Ссылки на Test Project и Release Gate обновлены до TP 5.3.
