Сладкий Забег — расширенные награды для «Акций магазина»
Дата: 13.08.2026

ИЗМЕНЕННЫЕ ФАЙЛЫ
- owner.html
- index.html
- src/worker.js

ЧТО ДОБАВЛЕНО
1. Конструктор акций теперь группирует награды по разделам:
   - Ресурсы
   - Сезонный пропуск
   - Усилители
   - Кейсы
   - Оформление: аватары, рамки, следы, скины, музыка
   - Физические награды

2. В акцию можно добавить существующие игровые предметы оформления:
   - аватарки;
   - рамки;
   - следы;
   - скины;
   - музыкальные треки.
   Используется только уже выпущенный текущий каталог игры. Будущий сезонный контент не публикуется через акции раньше релиза.

3. Добавлена награда «+ уровни сезонного пропуска»:
   - от 1 до 25 уровней;
   - работает только при активном сезоне;
   - сервер проверяет текущий уровень и не показывает/не продает набор, если полная обещанная прибавка вывела бы игрока выше 50 уровня;
   - начисление выполняется сервером через существующий season_pass_players.

4. Бустеры ×2 очки / ×2 зефир / ×2 кофе получили настройку общего числа забегов:
   - от 2 до 40;
   - только четное количество;
   - сервер преобразует число забегов в существующие штатные усилители по 2 забега;
   - существующая механика активации бустеров и settlement забега не изменена;
   - старые акции с прежними типами бустеров продолжают работать, а при редактировании автоматически отображаются в новом формате.

5. Уникальные награды оформления защищены от повторной покупки:
   - если предмет уже есть у игрока, такая акция ему не показывается;
   - сервер повторно проверяет владение непосредственно перед покупкой;
   - акция с уникальным предметом автоматически получает лимит 1 покупка на игрока.

6. После покупки клиент автоматически обновляет коллекцию/бустеры/сезонный пропуск, поэтому новая награда появляется без перезапуска игры.

7. Исправлено отображение количества наград во Flash Offer, чтобы серверные подписи с количеством не дублировались на клиенте.

МИГРАЦИЯ D1
Не требуется. Новые типы наград хранятся в существующем rewards_json и используют существующие таблицы игры.
