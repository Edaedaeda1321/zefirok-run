15.08.2026

ИСПРАВЛЕНО

1. RNG сезонных кейсов: groupChances больше не теряется при переносе Change Set в Test Project.
   Проценты групп «валюта / косметика / постоянные кейсы» в Sandbox совпадают с теми,
   которые затем публикуются в Production.

2. Безопасность сезонов в Staging:
   - создание сезона теперь сохраняется в Change Set и появляется как виртуальный сезон в TP;
   - изменение срока сезона теперь сохраняется в Change Set и тестируется в TP;
   - при включённом Staging сервер блокирует остальные сезонные мутации, которые ещё не имеют
     отдельной безопасной Sandbox-версии, поэтому они не могут случайно изменить Production.

3. Safe Promote:
   - убрана ложная пакетная «атомарность» нескольких разнородных изменений;
   - один Promote публикует ровно один READY-пункт;
   - сложные операции одного пункта (создание сезона, магазин, Live Content Manager)
     сведены в D1 batch, чтобы их связанные записи менялись вместе;
   - Release Report теперь явно помечает такой режим как SAFE 1x, а не ATOMIC-пакет.
