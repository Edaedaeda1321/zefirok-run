ИСПРАВЛЕНЫ ВСЕ HIGH-ПРОБЛЕМЫ ИЗ ПОСЛЕДНЕГО АУДИТА

1. READY больше не переживает редактирование
- Любое повторное сохранение READY-изменения автоматически возвращает его в SANDBOX.
- ready_at Change Set сбрасывается.
- После правки изменение нужно заново проверить и вручную перевести в READY.

2. S3 «Тайны Белкино» больше не может автоматически уехать в S4
- Автоподготовка сезонного кейса S3 получила постоянный preset marker.
- После первого определения сезон навсегда фиксируется по season_id.
- Старый generic-поиск «следующего будущего сезона» удалён.
- Когда привязанный S3 завершён, preset не пересаживается в следующий сезон.

3. Safe Rollback
- Rollback теперь выполняется строго по одному Production-изменению.
- Массовый последовательный rollback отключён, чтобы не получить частично откатившийся пакет.
- UI прямо запрещает выбрать несколько пунктов для rollback.

4. Защита от двух вкладок / параллельного Promote
- Добавлен owner-global staging lock.
- Пока Promote или Rollback выполняется в одной вкладке, другая вкладка не может одновременно
  публиковать, откатывать, менять Change Set, переключать Staging или редактировать его элементы.
- Lock имеет TTL и автоматически освобождается после завершения операции.
- После Dry Run непосредственно перед записью в Production повторно проверяется stale baseline.

5. Release Gate для нескольких сезонов
- Dry Run определяет все season_id, затронутые выбранным изменением/Change Set.
- QA/Release Gate запускается отдельно по каждому затронутому сезону.
- Итоговый Gate объединяет PASS/WARN/FAIL по всем сезонам.
- В TP показывается строка Season Gates с результатом каждого сезона.
- Виртуальный новый сезон из Staging также корректно проходит Season QA.

6. TP 5.2 UI сохранён и приведён к версии TP 5.3
- Сохранены режимы «Играть / Подготовить / Проверить / Инструменты».
- Сохранён reproducible RNG seed.
- Сохранены Release Reports.
- Версии и cache-bust обновлены до TP 5.3.
