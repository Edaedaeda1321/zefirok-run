Сладкий Забег — проверка готовности сезона / Control Center CC v9.18
Дата: 2026-08-13

Что добавлено
1. В Контент → Пропуск появился отдельный блок «Проверка готовности сезона».
2. Проверка анализирует выбранный сезон перед запуском:
   - корректность дат и отсутствие пересечений с другими сезонами/окнами наград;
   - все 100 активных наград (уровни 1–50, Бесплатно + Элитный);
   - обе финальные награды 50 уровня;
   - корректность ссылок на обычные/сезонные кейсы и косметику;
   - ежедневные и недельные задания;
   - опубликованные главы сюжета и отдельный сюжетный финал на 50 уровне;
   - письмо 50 уровня и его целевой будущий сезон;
   - сезонный кейс, его содержимое, изображения и дату релиза;
   - цены Элитного / Элитного+;
   - все используемые /assets/ изображения через assets/images-manifest.json.
3. Результат разделён на:
   - зелёные пункты — пройдены;
   - предупреждения — не блокируют запуск;
   - критические ошибки — блокируют ручной «Начать сейчас».
4. Кнопка «Начать сейчас» сама повторно запускает серверную проверку непосредственно перед стартом.
5. Серверный endpoint запуска также повторяет gate независимо от интерфейса — обход через прямой API не запускает явно неготовый сезон.
6. Control Center: CC v9.18.

Что НЕ считается критической ошибкой
- отсутствие сюжетов вообще;
- выключенное письмо;
- отсутствие сезонного кейса, если он нигде не используется;
- отсутствие одного из типов заданий;
- нулевая цена тарифа (показывается предупреждение).
Это позволяет намеренно запускать более простой сезон, но явно сломанный включённый контент блокируется.

Регрессионная проверка текущего изменяемого контура
- src/worker.js: node --check — OK;
- inline JavaScript owner.html — OK;
- inline JavaScript battle-pass.html последней версии — OK;
- duplicate HTML id в owner.html — 0;
- duplicate HTML id в battle-pass.html — 0;
- все 121 literal /api/owner/* вызова owner.html имеют соответствующие маршруты Worker — OK;
- все 15 literal /api/battle-pass/* вызовов battle-pass.html имеют соответствующие маршруты Worker — OK;
- регрессия с буквальным \\n перед стилями battle-pass.html не найдена.

Важно
Проверка картинок выполняется уже на задеплоенной сборке по assets/images-manifest.json, который ваш custom build генерирует перед wrangler deploy.
Автоматический старт по заранее установленной дате остаётся календарным механизмом. Поэтому будущий сезон нужно проверить кнопкой до его даты старта; серверный hard gate применяется к ручному «Начать сейчас».
