## Исправления

1. **Рейтинг, кнопка «Посмотреть итоги».** Окно монтировалось вне `#zefirok-maltipoo-runner`, а его CSS действовал только внутри этого узла. Для классов итогового модального окна исправлена область CSS; `hidden`, закрытие и кнопка «Забрать награду» по-прежнему работают.
2. **Итоги на главном экране игры.** Pop-up использует серверное `finale` для последнего закрытого сезона (даже когда следующий сезон уже начался); показывает итоговое место, очки, забеги, число участников, победителя и реальную награду при её наличии. Работает через существующий запрос рейтинга после Telegram-auth, без отдельного обязательного API-вызова. Показывается по одному разу на игрока за сезон; не прерывает активный забег или другой критичный диалог. Запись о просмотре создаётся только после настоящего открытия окна. Кнопка попапа ведёт в рейтинг.
3. **Telegram: потеря первого места.** Постановка и доставка допускают сезон со статусом `scheduled`, когда его `starts_at` уже наступил (до фонового перевода в `active`). Перед отправкой через 90 секунд система перепроверяет лидера и отменяет устаревшие уведомления. Если `bot_subscribers`-строка отсутствует, резервный адресат — Telegram ID игрока; явно отключённый чат не используется. Политика тихих часов и ограничение повторов остаются в силе. Отправка больше не очищает посторонние сообщения бота.
4. **Telegram: окончательный победитель.** Сохранено серверное закрытие сезона, очередь `player_mail:rating_winner:<season_id>`, отдельная кнопка «Итоги рейтинга», уникальность 1 уведомления на сезон (миграция 0116). Теперь при отсутствии строки `bot_subscribers` постановка не пропускает победителя с числовым Telegram ID; защита от явно выключенного чата остаётся. Существующее восстановление пропущенных пушей работает для закрытий за последние 7 дней.
5. **Мир Зеффи.** Совмещены ранее подготовленные изменения закрытого RC; allowlist и D1-проверки сохраняются, `world_tester=1` не возвращается.

**Не меняли:** призы/балансы, механику выдачи награды, порядок сортировки победителей, серверные критерии рейтинга, какие-либо действующие данные D1. Новой миграции В ЭТОЙ итерации нет; миграция 0116 из предыдущего патча включена на случай, если тот ещё не был установлен.

## Как установить на Mac

1. Сохраните ZIP в `~/Downloads/` и откройте Терминал в корне `zefirok-run`. `git status --short` должен быть чистым. Если есть локальные изменения — сначала сохраните их и разберите конфликты.
2. Распакуйте ZIP командой из `COMMANDS_MAC_RU.txt`.
3. Запустите указанные проверки и убедитесь, что все прошли.
4. Проверьте удалённый список миграций; если `0116` ещё не применена, примените миграции штатной командой Wrangler **до публикации Worker**. Если список содержит неожиданные миграции, сначала разберите их.
5. Коммит только файлов из ZIP, `git push origin main`, затем штатный `./update.sh` (не `npx wrangler deploy`).

## Как убедиться, что уведомления реально отправляются

Команды для диагностики D1 есть в `COMMANDS_MAC_RU.txt`, SQL — в `NOTIFICATION_DIAGNOSTICS.sql`.

`player_notification_queue.status = 'sent'` означает, что Telegram API подтвердил отправку. `pending` означает ожидание 90 секунд, тихих часов или обработки. `failed` — ошибка/повтор. `cancelled` — прежний лидер успел вернуться на первое место или сезон уже закрыт. Сообщения не должны отправляться мгновенно в момент фиксации каждого временного изменения первого места.

Если в `leaderboard_seasons` нет нового **окончательно закрытого** сезона, пуш победителю и попап итогов не должны появляться. Если итоговая награда не была выдана сервером, клиент не создаёт фиктивную награду.
