# Сладкий Забег — Seasonal Case Main Game Style Hotfix v3

## Почему понадобился v3

Предыдущий v2 был ошибочно собран поверх устаревшего `battle-pass.html`. Из-за этого при замене файла откатились части уже исправленного интерфейса сезонного пропуска: динамическая идентичность сезона, счётчики вкладок, ограничения/поведение ленты наград, часть надёжной логики сезонных кейсов и защита от автопопапов во время обучения.

v3 пересобран заново от актуального `battle-pass.html` из `main`.
Базовый blob SHA GitHub: `2af9ca0063575c35ccbca37dcd895dfa8066f2f8`.

## Что сохранено / восстановлено

- Активный сезон снова берётся с сервера: `Сезон 2 — Ночь сладких чудес`, без отката на статический `Сезон I`.
- Вкладки сезона/заданий и их отдельные счётчики сохранены.
- Центрирование карточки истории сезона и кнопки сохранено.
- Кнопка `?` остаётся закреплённой справа.
- Лента наград остаётся на исправленной transform-механике без пустого overscroll и без отката к старому native scroll.
- Надёжное `Получить все награды` с повторной authoritative-проверкой сохранено.
- Сезонные кейсы сохраняют requestId, `/seasonal-case/status`, восстановление после перезапуска и 70-секундное окно проверки.
- Блокировка автопопапов во время обучения сезона сохранена.
- LiveOps-картинки тарифов/активации и динамическая картинка финального кейса сохранены.

## Что добавлено поверх актуальной версии

- Анимация открытия сезонного кейса в стиле основной игры с ночным фоном сезона 2.
- Используются закрытая и открытая картинки конкретного сезонного кейса.
- Тап по кейсу ускоряет reveal.
- В окне `Вот это улов!` показывается открытый сезонный кейс и подпись `СЕЗОННЫЙ КЕЙС`.
- `icon_prize.png` сохранён для замены подарочного emoji в сезонном сюжетном UI этого файла.
