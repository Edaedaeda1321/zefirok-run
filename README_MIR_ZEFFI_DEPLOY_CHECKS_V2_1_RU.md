## Установка

Команды выполнять из корня `zefirok-run`.
Сначала проверить `git status --short`. Уже установленные и подготовленные
к коммиту изменения City Fix v2 не откатывать. `git pull`/повторная установка
старых архивов для этого исправления не требуются.

Скачать `Mir_Zeffi_Deploy_Checks_v2_1_AutoInstall.zip` в «Загрузки».

```bash
(
set -e

git status --short

unzip -o "$HOME/Downloads/Mir_Zeffi_Deploy_Checks_v2_1_AutoInstall.zip" -d .

python3 scripts/apply-world-checks-v2-1.py --check
python3 scripts/apply-world-checks-v2-1.py

node scripts/check-world-checks-v2-1.mjs
node scripts/check-world-city-fix-v2.mjs
node scripts/check-world-story-v1.mjs

node --test world/tests/*.test.mjs
node --no-warnings --experimental-sqlite scripts/check-zeffi-world-integration.mjs
node scripts/check-production-gate.mjs

git diff --check
git diff --stat
git status --short
)
```

В блоке намеренно нет строк-комментариев с `#`: у пользователя они ранее
прерывали выполнение в интерактивном zsh. Использовать команды без добавления
таких строк. Не включать обход ошибок, `--skip-d1` или отключение проверки пробелов.

Установщик выполняет полный preflight до записи, отказывается от симлинков,
неизвестных версий и повреждённых файлов, сохраняет резервную копию и откатывает
уже выполненные записи при сбое. Повторная установка безопасна.
Он не выполняет Git, сетевые запросы, миграции или деплой.

## Git и публикация

Только после успешного завершения полного предыдущего блока.
`git add -A` обновит ранее подготовленные версии файлов: это важно, если
старый файл с пробелом уже находится в индексе Git. Проверить, что среди
локальных изменений нет посторонних файлов.

```bash
(
set -e

git diff --check

git add -A
git diff --cached --check
git diff --cached --stat

git commit -m "fix(world): finalize city v2 and repair release checks"
git push origin main

./update.sh

git status --short
git log -1 --oneline
)
```

Если любой тест или gate снова завершился ошибкой — остановиться, не переходить
к следующему блоку. Не использовать `git reset --hard`, принудительную
перезапись файлов, `--no-verify`, force push или прямой `npx wrangler deploy`.
