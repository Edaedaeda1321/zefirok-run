Сладкий Забег — hotfix вкладки Season Pass в Control Center
Дата: 2026-09-14

Что исправлено
1. Убрана смена глобальной версии runtime-schema для всей системы Season Pass из-за новой настройки 50+.
   Эта смена заставляла ensureSeasonPassSchema считать production-схему устаревшей и запускать тяжёлый полный bootstrap/seed/reconcile сезонного пропуска.
2. Настройки бесконечной линии 50+ вынесены в отдельную лёгкую проверку схемы ensureSeasonPassOverflowSchema.
   Она проверяет/добавляет только 5 новых колонок и не запускает полную миграцию/пересчёт игроков.
3. /api/owner/season-pass перед чтением настроек 50+ запускает только эту лёгкую проверку.
4. Сохранение настроек 50+ также использует только лёгкую проверку.

Файлы
- src/worker.js — заменить текущий файл. Он основан на предыдущем патче profile/mail/overflow и сохраняет все его изменения.
- owner.html — приложен для сверки; содержательно это тот же owner.html из предыдущего патча.

Важно
Патч не меняет battle-pass.html и index.html, чтобы не затереть ваши текущие локальные изменения.
