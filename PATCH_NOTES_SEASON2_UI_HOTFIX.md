# Сладкий Забег — Season 2 UI Hotfix

База: актуальная сборка `Game.zip`, предоставленная 13.09.2026.

## Исправлено

1. **Сезонный пропуск показывает старый Сезон I**
   - Удалена жёсткая привязка интерфейса к `Сезон I: Открытие Кафе`.
   - Заголовок и вкладка сезона теперь строятся из серверного `season.title / season.id`.
   - Для текущего сезона корректно отображается `Сезон 2: Ночь сладких чудес`.
   - Число доступных наград больше не выглядит как номер сезона: оно вынесено в отдельный счётчик.

2. **Обучение профиля съезжает при прокрутке пальцем**
   - На время контекстного обучения блокируется прокрутка/свайп фонового интерфейса.
   - После закрытия/завершения обучения блокировка корректно снимается.
   - Колесо мыши также блокируется во время активного шага обучения.

3. **Сломанные иконки в достижениях и закрытых наградах**
   - Исправлены неверные `.png` пути на существующие `.webp` ассеты:
     - `icon_goal.webp`
     - `icon_vitrina.webp`
     - `icon_closed.webp`
     - `icon_warning.webp`

4. **Сломанное изображение награды в сюжете сезона**
   - Сервер теперь дополняет старые story-reward записи каноническими title/image для `points`, `treats`, `coffee`, `case`.
   - Клиент дополнительно предпочитает канонические картинки ресурсов, если в старой записи лежит пустой/устаревший путь.

5. **Сломанные изображения наград в Battle Pass**
   - Для ресурсов и кейсов добавлен клиентский canonical fallback.
   - Для кейсов сервер больше не отдаёт устаревший `image_url`, если `itemId` однозначно определяет актуальную картинку.
   - Это исправляет, в том числе, 404-картинку финальной награды сезона.

6. **На главной странице виден текст `" title="Сладкий Забег`**
   - Исправлена граница `data-srcdoc` главного iframe: атрибут `title` снова является атрибутом iframe и больше не попадает внутрь HTML игры как видимый текст.

## Изменённые файлы

- `battle-pass.html`
- `achievements.html`
- `src/worker.js`
