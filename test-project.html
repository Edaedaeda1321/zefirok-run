Настоящая игра · Sandbox

TP 3.1 запускает текущий production-интерфейс игры, но все игровые API перехватываются изолированным owner-only proxy.

В sandbox используются отдельный localStorage, виртуальный игрок, виртуальное время и Draft Layer. Telegram CloudStorage отключён. Неподдерживаемый /api/* запрос блокируется вместо выхода в Production.
