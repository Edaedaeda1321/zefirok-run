# Мир Зеффи — тестирование двух городов и большой парк «Белкино» v1

Патч собран под `main` после «Story Tester Gate Fix» (`599594f...`).

**Что делает:**
- Публикует на общей карте большой парк Белкино 9x9 клеток, четыре WebP-ракурса и исправленные пешеходные тропинки. Только общий сюжетный город — никакой покупки в личном магазине.
- Исправляет избыточный отступ верхней панели в Telegram на мобильных устройствах; компактно размещает шапку, меню и карту.
- Добавляет доступное тестерам переключение «Общий город / Мой район».
- Для «Мой район» сначала пробует существующий защищённый `/api/world/state`: если сервер разрешил, показывает **настоящий персональный город D1** с прежними флагами покупок.
- Если `WORLD_ENABLED` выключен, после **отдельной проверки подписанной Telegram-сессии и списка тестеров** через read-only `/api/world/story-access` запускает полноценную **локальную песочницу** с тестовыми валютами. Она хранится только в этом браузере и не пишет в D1 / не списывает реальные валюты.
- Для обычных игроков остаётся прежняя заглушка. Флаги `WORLD_ENABLED`, `WORLD_PURCHASES_ENABLED` и `WORLD_STORY_ENABLED` НЕ меняет.

**Проверка и установка:**
Из корня `zefirok-run` (рядом с `index.html`):

```bash
python3 scripts/apply-zeffi-dual-belkino-v1.py --check
python3 scripts/apply-zeffi-dual-belkino-v1.py
node scripts/check-world-dual-v1.mjs
node scripts/check-world-api-wiring.mjs
node scripts/check-world-park-belkino-v1.mjs
node scripts/check-world-story-v1.mjs
node scripts/check-world-api-wiring.mjs
node --test world/tests/*.test.mjs
node --no-warnings --experimental-sqlite scripts/check-zeffi-world-integration.mjs
node scripts/check-production-gate.mjs
```

Скрипт перед записью проверяет SHA-256 **всех** файлов; не затирает неизвестные локальные версии, сохраняет резервную копию в `.world-story-v1-backup/` (уже исключена из Git и публикации). Не требуется повторно ставить отдельный старый ZIP Белкино.

**Верификация в Telegram:**
1. Войти разрешённым тестером, нажать «Мир Зеффи» — общий город.
2. На вкладке «Белкино» увидеть большой парк с прудом, ротондой, топиариями и руинами (9x9).
3. Вверху нажать «Мой район» — откроется существующий D1-город, если он разрешён сервером, иначе песочница с явной жёлтой информационной полосой.
4. Во вкладке навигации личного города «Общий мир» снова открыть общий город.
5. Обычный пользователь, не входящий в `WORLD_TESTER_IDS`, не должен получить доступ ни к одной странице.
6. Убедиться, что Telegram-системная панель сверху НЕ создаёт второй большой отступ в интерфейсе.

**Предупреждение:** если D1-режим личного города включён, его покупки подчиняются реальным серверным правилам и могут использовать реальные валюты; при отключённом `WORLD_ENABLED` личный город работает как локальная песочница без реальных трат.

**Без миграций.** Worker/auth/D1 server-service не изменяется. Код проигрывателя раннера и `profile.html` не затрагиваются.

**Публикация** только после полного прогона `node scripts/check-production-gate.mjs` на Mac и проверки staged файлов. `git push origin main`, затем `./update.sh` (не прямой Wrangler).
