# Мир Зеффи — общий сюжетный город v1

## Две сборки

**Production-патч для тестеров** добавляет отдельную сюжетную карту в существующую игру. Вход: **Мир Зеффи → Общий мир → V1 · ТЕСТ**. Открывается `story-world.html?story_tester=1`, но параметр не даёт доступа: сервер проверяет подписанную Telegram-сессию и существующий список тестеров.

**Автономная сборка** — `START_STORY_WORLD.html`. Распакуйте ZIP в отдельную папку и откройте этот файл в современном браузере. Сервер, Python, Node.js, Telegram и Интернет для запуска не нужны: все 37 используемых игровых WebP и код находятся внутри HTML. Браузер может ограничивать локальное сохранение; тогда тест работает в памяти, и об этом есть уведомление.

## Важно: что означает v1

Это первая исследуемая сюжетная карта и демонстрация будущего коллективного строительства. **Даже в production-входе для тестеров прогресс проекта локальный.** Игроки пока не складывают реальные ресурсы в общую серверную шкалу. Нет реальных наград, списаний кофе/зефира/очков, новой валюты в кошельке или синхронизации вкладов между игроками.

Личный город не читается и не перезаписывается. Используется отдельный ключ `zefirok-story-world-demo-v1`. Число материалов сообщества — явно обозначенная тестовая величина, не статистика настоящих игроков.

## Что можно проверить

- Авторская карта 48×48: в четыре раза больше по числу клеток, чем стартовая карта 24×24 личного города.
- Восемь районов: центральная площадь; кафе «Зефирок»; парк Белкино; квартал друзей; городская станция; площадка событий; «Белый Кролик»; неизвестный будущий район.
- В стартовом сценарии 141 размещённый объект, 262 дорожные клетки, 12 декоративных жителей и 2 автобуса. Сцены используют действующие модули живого города.
- Панорамирование, масштабирование колесом/кнопками/жестом двух пальцев, клавиатура, мини-карта, быстрые переходы в районы и карточки мест.
- Серые закрытые зоны с вопросительными знаками. В панели «Тест v1» этап 2 показывает площадку событий, этап 3 — «Белого Кролика». Неизвестный район остаётся закрытым.
- Городской проект «Сад встреч»: вклад 25/50/100 тестовых материалов, точное ограничение последнего взноса, строительство 45 секунд, отдельное открытие готового сада.
- Пауза анимации, остановка фонового рендеринга при скрытии страницы, поддержка reduced motion, отдельный сброс теста.

### Быстрый сценарий проверки стройки

1. Откройте «Проект» и внесите 100 материалов.
2. В «Тест v1» дважды нажмите «Сымитировать помощь сообщества +200».
3. Вернитесь к проекту и дважды внесите по 100. Последний взнос автоматически уменьшится до 60: всего получится 1000/1000.
4. Закройте карточку и посмотрите стройку на карте возле парка Белкино. Через 45 секунд появится кнопка открытия сада.
5. Откройте сад; затем смените тестовый этап сюжета и проверьте появление новых объектов.
6. «Тест v1 → Сбросить только этот тест» возвращает начальный сценарий, не затрагивая личный город.

## Сюжет и графика

Использованы существующие игровые WebP, изометрический рендерер, жители и автобусы — новые изображения не заменяют утверждённые ассеты. «Зефирок», Белкино и «Белый Кролик» взяты из известного контекста проекта. «Квартал друзей» — рабочее обозначение, без приписывания неподтверждённых персонажей. Для «Белого Кролика» временно используется существующая вилла: это не готовый уникальный арт стоматологии. «Сад встреч» — новый демонстрационный проект, а не ранее утверждённая сюжетная глава. Тестовые этапы не меняют реальные сезоны и задания.

## Источник и безопасность установки

В начале задачи проверен свежий `main`: `b1a92576eb90b94dae6e5d2bf33482c09e443c2a` — `feat(world): add living city NPC interactions and buses`.

Установщик проверяет SHA-256 используемых модулей движка, каталога, жителей, автобусов, манифеста и Worker. Он не заменяет их старыми версиями. При несовместимости останавливается. Изменения `world.html`, серверного сервиса и production gate точечные; посторонние изменения вокруг точных совпадающих вставок сохраняются. Все цели и payload проверяются до первой записи. Повторная установка — `ALREADY`. Симлинки и частично установленные/дублированные вставки запрещены.

До изменения файлов создаётся резервная копия в `.world-story-v1-backup/<дата-идентификатор>/before/` и `receipt.json`. При ошибке записи уже применённые изменения автоматически возвращаются. Резервные копии и автономные HTML исключены из Git/публикации. Не копируйте весь старый проект поверх свежего main при конфликте.

Распаковка production ZIP добавляет установщик, payload и эту инструкцию; рабочие файлы мира изменяются только запуском Python-установщика.

## Установка production-патча

Команды выполняются из корня `zefirok-run`. Сначала проверьте, что локальные изменения понятны и сохранены. Не делайте автоматический stash/reset и не игнорируйте ошибки проверок. Обёртка ниже останавливает выполнение при первой ошибке.

```bash
(
set -e

git status --short
git switch main
git pull --ff-only origin main

unzip -o "$HOME/Downloads/Mir_Zeffi_Story_World_v1_AutoInstall.zip" -d .

python3 scripts/apply-world-story-v1.py --check
python3 scripts/apply-world-story-v1.py

node scripts/check-world-story-v1.mjs
node --check world/story/app.js
node --check world/story/boot.js
node --check src/zeffi-world-service.js
node --check world/app.js
node --check world/renderer.js
node --test world/tests/story-world-v1.test.mjs world/tests/story-access-v1.test.mjs
node --test world/tests/*.test.mjs
node --no-warnings --experimental-sqlite scripts/check-zeffi-world-integration.mjs
node scripts/check-production-gate.mjs

git diff --check
git status --short
)
```

В проверенной исходной версии есть 11 ошибок полного набора world/tests; они не исправляются и не отключаются этим патчем. Если они воспроизведутся, блок остановится. Не выдавайте такой прогон за успешный и не публикуйте изменения без разбора причин. Подробности и ограничения среды — в `world/docs/STORY_WORLD_V1_CHECKS_RU.md`.

### Git и production — только после успешных проверок

Проверьте `git status`: `git add -A` включает все изменения, не только этот патч.

```bash
(
set -e

git diff --check
git add -A
git diff --cached --check
git commit -m "feat(world): add tester story world v1 and offline prototype"
git push origin main
./update.sh

git status --short
git log -1 --oneline
)
```

`./update.sh` остаётся штатным процессом публикации. Прямой `npx wrangler deploy` не нужен. Этот архив не выполняет Git, миграции или деплой самостоятельно.

## Доступ тестеров и сервер

Используются существующие `WORLD_ENABLED` и `WORLD_TESTER_IDS`. Новый `POST /api/world/story-access` вызывает действующую проверку Telegram и allowlist, затем возвращает только разрешение открыть локальный тест. Он не создаёт личный город, не читает D1, не загружает профиль и не трогает кошелёк. Миграций нет. `/api/world/state` и `/api/world/mutate` не изменены.

Новый endpoint доступен разрешённым тестерам после установки. Дополнительный необязательный аварийный переключатель `WORLD_STORY_ENABLED`: если переменная задана и не равна `true`, новый вход закрывается; отсутствие переменной не блокирует вход уже разрешённого тестера. Это не замена существующей проверке `WORLD_ENABLED` и allowlist. `wrangler.jsonc`, `update.sh` и списки тестеров патч не меняет.

Параметры `story_tester=1`, `offline=1`, изменение localStorage и открытие hosted HTML на localhost сами по себе не дают доступа через production-экран. Автономная версия поставляется отдельно, не загружается в production и не содержит серверных секретов.

Статические игровые ассеты и клиентский код не являются секретами; gate защищает штатный вход тестеров, а не пытается скрыть исходники. Реальных общих операций, требующих дополнительных серверных проверок, в v1 нет.

## Изменения по файлам

Новые рабочие файлы:
- `story-world.html` — отдельный экран;
- `world/story/boot.js` — проверка доступа перед загрузкой карты;
- `world/story/entry.js` — подключение существующей кнопки общего мира;
- `world/story/app.js` — камера, карточки, жизненный цикл, локальная симуляция;
- `world/story/map.js` — районы, фиксированная карта, условия появления;
- `world/story/model.js` — изолированное локальное состояние и пробные вклады;
- `world/story/view.js` — камера, UI-иконки, выбор существующих спрайтов;
- `world/story/style.css` — мобильный интерфейс;
- `world/tests/story-world-v1.test.mjs`, `world/tests/story-access-v1.test.mjs` — тесты;
- `scripts/check-world-story-v1.mjs`, `scripts/build-world-story-v1.py` — проверки и воспроизводимая автономная сборка.

Точечные изменения существующих: `world.html`, `src/zeffi-world-service.js`, `scripts/check-production-gate.mjs`, `.gitignore`, `.assetsignore`.

Не изменены: `index.html`, личный `world/app.js`, `world/engine.js`, `world/renderer.js`, каталог, жители, автобусы, спрайты, `src/worker.js`, `wrangler.jsonc`, `update.sh`, миграции и игровые данные. Неиспользуемый `profile.html` не входит в работу.

### Пересборка автономного HTML из исходников

Для пересборки нужны Python 3 и Node.js 22, но не npm-пакеты и не доступ в Интернет:

```bash
python3 scripts/build-world-story-v1.py
```

Результат: `.story-standalone-output/START_STORY_WORLD.html`. Сборщик берёт именно эти модули и 37 нужных игровых изображений, не копирует весь каталог assets, не использует eval и не включает hosted-авторизацию.

## Следующий серверный этап — не входит в v1

Настоящие общие вклады потребуют отдельного серверного состояния проекта, журнала вкладов, атомарной защиты кошелька/идемпотентности, правил доступности, миграции и общей выдачи результата. Клиентская модель v1 не должна использоваться как доверенный источник этих данных.
