# Сладкий Забег — Премьера сезона V1.2: сразу при входе

## Причина задержки

В V1 приветствие главного экрана запускалось с дополнительной паузой `delay:1150` **после** уже полученного подписанного состояния сезона. Параллельно данные о сезоне передавались только на позднем шаге обработки игрового стартового пакета. Визуальная анимация карточки длилась 0,55 с. Если окно обучения перекрывало этот момент, старый V1 мог пропустить презентацию до следующего входа.

## Что изменено

1. Главный экран вызывает презентацию синхронно с приходом доверенного сообщения от игрового iframe: `delay:0`. Не ждёт ещё 1150 мс.
2. Уже загруженные сервером данные `seasonPassBonus.premiere` передаются из авторизованного стартового пакета **до** необязательных обновлений профиля, достижений и иных UI-блоков. Поздний прежний сигнал остаётся как резервный. Запросы не добавлены.
3. Если интерфейс занят более приоритетным окном или Telegram свёрнут, новая проверка идёт сначала раз в 120 мс, позже реже. Приветствие **не** считается просмотренным до его фактического появления.
4. Длительность появления главной карточки снижена до 0,16 с. Анимация отключается, если пользователь запросил снижение движения в настройках устройства.
5. Используются уже существующие WebP-арты проекта. Эмодзи и новых рисунков нет.

## Правила остаются прежними

- Приветствие появляется автоматически **один раз на игрока и сезон**, а не при каждом входе.
- Показывается только у действующего сезона и только если «Приветствие главного экрана» включено и сохранено в CC.
- Не показывается до получения подтверждённых данных сервера и Telegram-авторизации. Под «сразу» понимается отсутствие лишней задержки после самого раннего проверенного стартового ответа, а не показ непроверенных устаревших данных.
- Системные модальные окна и обучение сохраняют приоритет. Через них премьера не показывается.
- Не изменяются пропуск, рейтинг, их награды, валюта, таблицы D1 или права доступа.

## Установка поверх V1

Ставить предыдущий ZIP V1.1 **не требуется**: этот патч уже включает его исправления повторного показа и источников Telegram initData. Установщик безопасен при повторном запуске и умеет работать поверх V1 и V1.1.

Из корня `zefirok-run`:

```bash
git status --short
git pull --ff-only origin main
unzip -o ~/Downloads/Sladkiy_Zabeg_Season_Premiere_Instant_V1_2_2026-10-16.zip -d .
node scripts/apply-season-premiere-instant-v1-2.mjs
node scripts/check-season-premiere-instant-v1-2.mjs
node scripts/check-season-premiere-v1.mjs
node scripts/check-index-srcdoc.mjs
npm run check:fast
git diff --check
```

После успешных проверок и контроля diff:

```bash
git add index.html battle-pass.html rating.html owner.html
git add scripts/season-premiere/ui.js scripts/season-premiere/ui.css scripts/season-premiere/ui-v1-2.js
git add scripts/apply-season-premiere-instant-v1-2.mjs scripts/check-season-premiere-instant-v1-2.mjs
git diff --cached --stat
git commit -m "Show season premiere immediately after authenticated startup"
git push origin main
./update.sh
```

Не используй самостоятельный `wrangler deploy`: применяй штатный `./update.sh`.

## Проверка в Telegram

В CC настрой активный сезон: «Сезонный пропуск» → «Визуал» → «Премьера нового сезона» → «Главный экран» → включить, сохранить. Приветствие откроется сразу после первого подтверждённого серверного ответа на авторизованном входе. Если **этот же игрок уже видел премьеру** в текущем сезоне, нового автоматического окна не будет: это намеренная защита от повторов. Для проверки внешнего вида используй предпросмотр CC либо проверь следующую премьеру на тестовом игроке, который её ещё не видел.
