# Мир Зеффи — Живой город v1 (самоустанавливающийся патч)

Этот архив **заменяет предыдущий `Mir_Zeffi_Living_City_Patch_v1.zip`** и устанавливается непосредственно в корневую папку репозитория `Edaedaeda1321/zefirok-run`, по той же схеме, что и `Mir_Zeffi_Shop_Locked_Cards_v18_patch.zip`.

**Важно:** новый ZIP *не содержит заменяемых* `world/app.js` / `world/renderer.js` в корне архива. Распаковка добавляет только установщик, проверку и защищённый пакет исходников в `scripts/`. Реальные файлы мира меняются **только при запуске установщика** после полной предварительной проверки.

## Команды (из корня репозитория)

```sh
git status --short
git switch main
git pull --ff-only origin main

unzip -o "$HOME/Downloads/Mir_Zeffi_Living_City_v1_AutoInstall.zip" -d .

python3 scripts/apply-world-city-life-v1.py --check
python3 scripts/apply-world-city-life-v1.py

node scripts/check-world-city-life-v1.mjs
node --check world/app.js
node --check world/renderer.js
node --check world/citizens.js
node --check world/traffic.js
node --test world/tests/city-life.test.mjs world/tests/citizens.test.mjs world/tests/citizen-footprint-occlusion-v15.test.mjs
node --test world/tests/*.test.mjs
node --no-warnings --experimental-sqlite scripts/check-zeffi-world-integration.mjs
node scripts/check-production-gate.mjs
git diff --check
git status --short
```

Если папка проекта уже содержит незакоммиченные изменения, **не сбрасывайте их**: сначала посмотрите `git status --short` и выясните происхождение. Если `--check` сообщает `ERROR`, не запускайте установку и не заменяйте `world/*.js` вручную — возможен новый код в `main`. При успешной повторной проверке патча в уже обновлённом проекте установщик покажет `ALREADY` и не сделает повторных изменений.

**Примечание о тестах:** на исходной приложенной сборке полный пакет world-тестов уже имел 11 падающих проверок до работы над этой механикой. Они остались теми же после первого патча. Целевые 21 теста были зелёными. Не считайте провал полного набора автоматически новой регрессией, но и **не проводите production-деплой при неразобранном падении обязательных release-gate проверок**.

После успешной проверки кода и release gate (выполнять самостоятельно, не автоматически):

```sh
git diff --check
git add -A
git commit -m "World Zeffi: living city citizens and buses"
git push origin main
./update.sh
```

Не использовать `npx wrangler deploy` напрямую.

## Что именно устанавливается

- `world/citizens.js` — разновидности жителей, прогулки к игровым объектам, анимации отдыха, кафе, игровых площадок, безопасная навигация. Целиком обновляется только если файл совпадает с проверенной базой 11.10.2026 (или уже идентичен текущей версии).
- `world/traffic.js` — новая визуальная система автобусов между готовыми, связанными дорогами остановками.
- `world/tests/city-life.test.mjs` — проверки поведения жителей, автобусов, маршрутов и отсутствия влияния на валюты/сохранение.
- `world/renderer.js` — точечная вставка отрисовки автобусов и порядка слоёв, без перезаписи остального рендера.
- `world/app.js` — точечное подключение автобусов в существующий жизненный цикл и кадры, без перезаписи остального приложения.
- `scripts/check-world-integration.mjs` — проверка наличия новых игровых модулей.
- `scripts/check-production-gate.mjs` — новый пункт world-проверок в общем release gate.

В архиве также находятся:

- `scripts/apply-world-city-life-v1.py` — **самоустановщик**. Опция `--check` ничего не меняет; без опции применяется патч. Есть дополнительная `--root /path/to/project`.
- `scripts/check-world-city-life-v1.mjs` — интеграционный smoke-check.
- `scripts/.world-city-life-v1/manifest.json` — точные шаблоны замен, хеши нового кода, версия.
- `scripts/.world-city-life-v1/world/` — проверенные новые модули, которые копируются **только через установщик**.

### Правила безопасности

1. До первой записи проверяется полный набор из семи целевых файлов, включая SHA-256 добавляемых исходников.
2. Для `app.js`, `renderer.js` и двух существующих проверочных скриптов применяются только точные, уникальные совпадения фрагментов. Остальные изменения текущего `main` сохраняются. Конфликт останавливает установку.
3. Существует защита от повторной установки и дублированных интеграций.
4. При файловой ошибке во время установки предпринят откат уже заменённых файлов.
5. **Никаких изменений Worker/D1, миграций, кошелька, экономики, API или серверных наград**. Поведение NPC и движение транспорта клиентские и визуальные.
6. Данные клиента, строительство, хранилище, маршруты дорог и статус построек не мигрируются и не пересоздаются.
7. Пакет установщика находится внутри `scripts/`, который исключён из Cloudflare статических assets через существующий `.assetsignore`.

### Проверки при подготовке

Проверено на копии исходных файлов проекта: проверка `--check`, установка, повторное применение (`ALREADY`), сохранение стороннего изменения `app.js`, `node --check` для файлов, новый smoke-check и **21/21** целевых тестов. Отдельная негативная проверка показала отказ при конфликте и отсутствие записей после неуспешного `--check`. Проверка после реального `git pull` и полный production gate должны быть запущены в вашем репозитории.
