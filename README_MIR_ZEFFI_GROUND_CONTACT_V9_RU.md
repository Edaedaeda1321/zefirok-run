# Мир Зеффи — Ground Contact Fix v9

## Назначение

Устраняет ощущение, что все постройки (дома, магазины, фонтаны, цветники, скамейки, деревья, парки и прочий декор) парят над газоном. Это исправление только визуального слоя, а не игрового состояния.

### Исправления

1. В основной изометрической отрисовке Canvas добавлена мягкая тень, закреплённая за геометрическим центром *фактически занимаемых клеток* каждого объекта. Тень появляется и во время стадии строительства, и при перетаскивании/предпросмотре места размещения.
2. Размер тени учитывает ширину спрайта. Маленькие скамьи, цветники и фонтаны не создают крупные тени на всю территорию.
3. Старые изображения `extra_flower_garden_{n,e,s,w}` использовали масштаб 4.6 и выглядели намного меньше положенных 3×3 клеток. Теперь только в случае старой версии их эффективный Canvas-масштаб нормализуется до 3.0, не меняя файлы WebP и метаданные.
4. Старые изображения `extra_playground_{n,e,s,w}` автоматически сопоставляются с фактическим footprint каталога (как старые 3×2, так и обновлённые 2×2), чтобы видимая основа совпадала с занимаемыми клетками. Уже исправленный пак v6 со scale 4.4 не меняется.
5. Для домов, киосков, пекарен, клумб, лавок, фонарей и других ассетов с корректной геометрией спрайт не передвигается и не растягивается. Добавляется только контакт с землёй.
6. Тень не рисуется под плоской плиткой-покрытием (`layer='surface'`), чтобы избежать затемнения дорожек и декоративных площадей.
7. Canvas radial gradient кэшируется для плавной работы на мобильных Telegram WebView. Дополнительные WebP, сетевые запросы или изменения ассетов не нужны.

### Что НЕ меняется

- Координаты, размеры, повороты и статусы объектов в сохранениях.
- Цены, уровни и валютные награды «Мира Зеффи» v7/v8.
- Worker, D1, платежи, серверная авторизация, кошелёк и миграции.
- Выбранные дизайны спрайтов и общий terrain.

### Файлы патча

- `world/renderer.js` — тень под каждым объектом, правильная геометрия постройки/стадий строительства/предпросмотра, исправление масштаба старых парков.
- `world/sprite-assets.js` — необязательные параметры Canvas-масштаба/якоря для одного изображения; старые вызовы неизменны.
- `world/tests/ground-contact-v9.test.mjs` — геометрия всех 41 объектов ×4 поворота; исправленные/старые спрайты; отсутствие изменения сохранений.
- `README_MIR_ZEFFI_GROUND_CONTACT_V9_RU.md` — эти инструкции.

### Установка и тесты

```bash
# В корне zefirok-run, при чистом git status
# Архив скачан через браузер в ~/Downloads
git status
git switch main
git pull --ff-only origin main
unzip -o "$HOME/Downloads/Mir_Zeffi_Ground_Contact_Fix_v9.zip" -d .

node --check world/renderer.js
node --check world/sprite-assets.js
node --test world/tests/ground-contact-v9.test.mjs
node --test world/tests/*.test.mjs
node --experimental-sqlite scripts/check-zeffi-world-integration.mjs
node scripts/check-world-api-wiring.mjs
git diff --check

git add world/renderer.js world/sprite-assets.js \
  world/tests/ground-contact-v9.test.mjs \
  README_MIR_ZEFFI_GROUND_CONTACT_V9_RU.md
git diff --cached --check
git commit -m "fix(world): ground all isometric buildings and decorative objects"
git push origin main
./update.sh
```

**Остановиться, если какая-либо проверка падает.** Никогда не выполнять отдельный `npx wrangler deploy` — штатная публикация через `./update.sh` только после `git push origin main`.
