# Сладкий Забег — Seasonal Case Granting Hotfix v1

База патча: актуальный `main` репозитория `Edaedaeda1321/zefirok-run` на момент задачи.

## Добавлено

### Операции игрока
- В Control Center → Игрок → Операции → «Выдать награду» появилась отдельная группа **«Сезонные кейсы»**.
- Можно выбрать конкретный сезонный кейс по его серверному `caseId` и выдать от 1 до 20 штук за операцию.
- Доступны выпущенные и включённые кейсы активных и завершённых сезонов; закрытые/будущие варианты показываются недоступными.
- Перед выдачей сервер повторно проверяет существование кейса, `enabled`, дату выпуска и фактический пул наград.
- Прямая выдача остаётся атомарной и идемпотентной через существующий `owner_grant_operations`; повтор неизвестного результата не должен создавать второй набор кейсов.
- Кейсы записываются в штатную `season_pass_case_grants` со snapshot содержимого на момент выдачи.

### Компенсации
- В Control Center → Компенсации → «Своя компенсация» появилась группа **«Сезонные кейсы»**.
- Можно добавить конкретный сезонный кейс в набор компенсации и указать количество 1–20.
- Перед созданием компенсации сервер проверяет, что кейс реально существует, выпущен, включён и имеет доступные награды.
- Доставка использует существующую `reward_delivery_queue` с `reward_kind=seasonal_case`; при доставке создаются штатные `season_pass_case_grants`.
- Для массовой своей компенсации сезонный кейс считается high-impact наградой и сохраняет существующие правила подтверждения/аудита.
