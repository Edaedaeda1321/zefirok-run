# Мир Зеффи — визуальный патч v13

Это точечное исправление двух проблем после интеграции New City v10 / City Levels v12:
1. У построек и декора заметен отрыв основания от травы.
2. Категории каталога показывают Unicode-символы вместо прежних премиальных WebP.

## Что делает патч

- `world/renderer.js`: сохраняет альфа-калибровку v11, добавляет второй, **отдельный** визуальный уровень посадки основания для домов, заведений, транспорта, парков и декора. Заглубление различается по категориям и набору спрайтов; ширина спрайтов, X-положение и логические footprint остаются прежними. Контактная тень становится глубже и дотягивается ближе к переднему краю изометрического основания. Тайл-поверхности, terrain и дороги не заглубляются.
- `world/app.js`: восстанавливает картинки WebP всех 8 категорий. `Транспорт` использует маленькую WebP-иконку, полученную из игрового спрайта вокзала. Если файл не загрузился, отображается старый символ, а не пустое место.
- `world/build-standalone.py`: встраивает изображения вкладок, шапки, каталога и всех трех валют в локальную автономную HTML-сборку.
- `assets/mir_zeffi/`: исходные игровые UI-иконки из v4/v5 без замены рисунков; новый только `icon_transport.webp` из существующего вокзала.
- `world/tests/visual-ground-icons-v13.test.mjs` и `scripts/check-world-visual-v13.mjs`: защитные проверки геометрии, 112 кадров New City, иконок и локального превью.

### Важно про исходные WebP

В части спрайтов **декоративный толстый цоколь или остров-подставка нарисован внутри самой картинки**. v13 заглубляет видимый край и добавляет контакт с землёй. Но полностью удалять художником нарисованную платформу из исходного WebP этот патч не обещает: для этого требуется отдельная графическая правка всех ракурсов. Поэтому реальный iPhone/Telegram нужно обязательно проверить после публикации.

Серверные методы, Worker, D1, очки/кофе/зефир, цены объектов, площадь клеток, положение объектов в сохранениях и стадии строительства **не изменяются**.

## Установка в существующий репозиторий

Архив `Mir_Zeffi_Ground_and_Catalog_Icons_v13_patch.zip` распаковать из `~/Downloads` в корень `zefirok-run`. Скрипт ниже добавляет точечные фрагменты в **текущие файлы**, а не заменяет их на более старые сборки. Перед записью проверяет наличие каждого фрагмента. При несовместимой версии прервётся без частично записанных исходников.

```bash
# Выполнять внутри папки zefirok-run, на своей актуальной ветке main.
git status --short
unzip -o "$HOME/Downloads/Mir_Zeffi_Ground_and_Catalog_Icons_v13_patch.zip" -d .
python3 scripts/apply-world-visual-v13.py

node --check world/app.js
node --check world/renderer.js
python3 -m py_compile world/build-standalone.py
node scripts/check-world-visual-v13.mjs
node --test world/tests/*.test.mjs
node --no-warnings --experimental-sqlite scripts/check-zeffi-world-integration.mjs
node scripts/check-world-new-city-pack.mjs
node scripts/check-production-gate.mjs

git diff --check
git status --short
```

**Если любая проверка завершилась ошибкой: НЕ делайте commit/push/deploy.**

Полный gate создаёт/перегенерирует `assets/images-manifest.json`; после gate добавьте изменённый файл в commit. Сначала проверьте состояние других несохранённых изменений из v12/production — **не используйте `git add .` или `git reset --hard`**.

```bash
git add world/app.js world/renderer.js world/build-standalone.py \
  world/tests/visual-ground-icons-v13.test.mjs \
  scripts/apply-world-visual-v13.py scripts/check-world-visual-v13.mjs \
  assets/mir_zeffi/ README_MIR_ZEFFI_GROUND_CATALOG_ICONS_V13_RU.md
# При изменениях после полного production gate:
git add assets/images-manifest.json

git diff --cached --check
git diff --cached --stat
# Если список соответствует ожидаемому:
git commit -m "fix(world): ground sprite foundations and restore category art"
git push origin main
./update.sh
```

## Автономное тестирование

Отдельный `Mir_Zeffi_Ground_and_Catalog_Icons_v13_OFFLINE.html` — одна HTML-страница со встроенными WebP и тестовым, не production-кошельком. Откройте её в браузере с диска. Серверный профиль и реальная D1 не используются.

Проверьте реальные 4 поворота у вокзала, домов, парков и площадок, 3 строительные стадии и полностью готовые объекты, отступы относительно дорог, каталог с 8 вкладками. Изображения источника имеют общую игровую перспективу; у некоторых из них выступающий художественный пьедестал, который не является ошибкой координат.

## Проверки при подготовке патча

- 90/90 игровых тестов, включая 112 состояний нового строительного набора.
- 22/22 проверки общей D1-экономики и разовых валютных наград.
- В Chromium мобильный интерфейс отрисован без ошибок JS, 8/8 категорий отобразились через WebP, валюты в автономном превью загружены.
- Автономный HTML собран с 361 WebP-спрайтом (часть старых спрайтов имеет общий фон/декоративные цоколи).
- Проверка в реальном Telegram на iPhone не проводилась.
