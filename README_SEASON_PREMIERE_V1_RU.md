# Премьера нового сезона V1 — Сладкий Забег

Источник для разработки: рабочий проект `Edaedaeda1321/zefirok-run`, актуальная ветка `main`.
Только существующие ассеты `/assets/...`. Новых изображений, рисунков и эмодзи в окнах нет.

## Что работает

**Основной экран.** После авторизованной загрузки `seasonPassBonus` из штатного `game/startup` (или штатной проверки бонуса) получает только разрешённые настройки приветствия и сезонный ID. Отдельный запрос D1 не создаётся. `postMessage` принимается только от оригинального iframe игры с совпадающим origin. Кнопка ведёт в существующий Сезонный пропуск.

**Сезонный пропуск.** После первого входа в активный сезон показывает «Сокровища сезона». Оформление, тексты и три особенности берутся из `season.visuals.battlePass.premiere.pass`. Обучение, сюжет, письма, получение тарифа и финальная награда не перекрываются. Есть кнопка «О сезоне» для повторного ручного просмотра.

**Рейтинг.** После первой авторизованной загрузки текущего рейтинга показывает «Новая гонка за лидерство», использует установленный в рейтинге `heroImage` и действующую награду за первое место. Итоги предыдущего сезона показываются в первую очередь; повторно окно открыть можно кнопкой «О сезоне».

**Частота.** Одно автоматическое приветствие на игрока, страницу и ID сезона, и не более одной автоматической премьеры за общую сессию; закрытие сохраняется локально. Ручной повторный просмотр доступен в пропуске и рейтинге. Будущие, завершённые и отключённые сезоны не показываются.

## CC: как настроить

1. `CC → Сезонный пропуск → Визуал → Премьера нового сезона` — две независимые панели «Главный экран» и «Сезонный пропуск». В каждой: переключатель, заголовок, подзаголовок, описание, три особенности, существующая обложка WebP и мобильный предпросмотр. Сохраняется штатной кнопкой «Сохранить визуал сезона».
2. `CC → Рейтинг → Визуал рейтинга → Приветствие рейтингового сезона` — такая же настройка, отдельная от пропуска; сохраняется штатной кнопкой рейтингового визуала.
3. Редактируй настройки **нужного** сезона до его старта. По умолчанию они выключены: включай только после загрузки и проверки изображений. В интерфейсах игроков настройки начнут действовать при активности соответствующего сезона.
4. Используй опубликованные пути `/assets/...` и кнопку «Выбрать из проекта». Существующая проверка изображений на Worker сверяет пути с `assets/images-manifest.json`. Для каждого поля обложки можно оставить пустое значение и использовать штатный арт.

## Архитектура, данные и безопасность

- `visuals_json` уже есть в `season_pass_seasons` и `leaderboard_seasons`, используется существующий формат `visuals.battlePass` / `visuals.rating`. **Новых D1-таблиц и миграций нет.**
- В существующих авторизованных ответах клиента дополняется только объект `premiere`; дополнительные SQL-запросы игрокам не добавляются.
- Сохраняются старые поля `heroImage`, `tariffs`, `storyCollectible`, `navigation`, `tasks`. Новый нормализатор режет длину текстов, проверяет типы и пути к изображениям, не вставляет пользовательский HTML.
- Не создаются новые награды, покупки, начисления, задания, сезонные события, обновления рейтинга и обходы ограничений.
- Существующий CSP страниц **не ослабляется**: новая презентация и её стили устанавливаются как статические inline-скрипты/стили, без дополнительных внешних вызовов. Исходные изображения уже принадлежат проекту.
- Патч не содержит больших оригинальных `index.html`, `owner.html` или `src/worker.js`: установщик читает **текущие** файлы проекта и вносит только конкретные замены. Неоднозначная или изменённая точка интеграции приводит к отказу с сообщением, а не к молчаливой порче.

## Установка

Открой Терминал в корне `zefirok-run`:

```bash
git status --short
git pull --ff-only origin main
unzip -o ~/Downloads/Sladkiy_Zabeg_Season_Premiere_V1_2026-10-16.zip -d .
node scripts/apply-season-premiere-v1.mjs
node scripts/check-season-premiere-v1.mjs
npm run check:fast
git diff --check
```

Если все проверки прошли:

```bash
git add index.html battle-pass.html rating.html owner.html src/worker.js \
  scripts/apply-season-premiere-v1.mjs scripts/check-season-premiere-v1.mjs scripts/season-premiere/
git diff --cached --stat
git commit -m "Add new season premieres for runner, pass and rating"
git push origin main
./update.sh
```

**Не используй** отдельный `npx wrangler deploy` и не обходи predeploy D1 gate. Важно: проверь `git status` перед установкой, чтобы не затереть посторонние изменения. После обновления полностью закрой и заново открой Telegram Mini App, чтобы снять старые страницы из кэша.

## Проверка на телефоне

- В CC выбери будущий сезон, активируй нужные поверхности и сохрани. Предпросмотр должен показывать настоящую обложку и фирменные иконки.
- После фактического старта сезона войди в игру и проверь основное приветствие. Кнопка должна открывать пропуск. При возврате окно не должно появляться снова.
- Если главное приветствие уже было показано в этой сессии, первое посещение пропуска и рейтинга не должно открывать новые окна автоматически. Для проверки дизайна нажми «О сезоне».
- На новой сессии окно для уже просмотренной страницы не должно повторяться. При новом ID сезона показ снова разрешается.
- Проверь, что обучение, письма, финалы сезонов и окна наград не перекрываются презентациями. Итоги старого рейтинга должны оставаться приоритетом.

## Проверки, доступные в комплекте

`node scripts/check-season-premiere-v1.mjs` проверяет серверные нормализаторы/слияние JSON, отсутствие новых запросов, права на автоматический показ, целостность точек интеграции, наличие штатных ассетов и отсутствие эмодзи в новом UI. `npm run check:fast` обязательно выполнить на полном актуальном репозитории.
