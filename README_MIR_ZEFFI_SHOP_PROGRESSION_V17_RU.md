# Мир Зеффи — Shop Balance & City Unlocks v17

## Что изменено

Это **точечное изменение актуальных файлов** действующего `zefirok-run`, не замена файлами из старой автономной игры.

- Пересчитаны цены **48** действующих покупаемых объектов в `world/economy.js`.
- Обычные постройки преимущественно за **очки**, премиальные — дополнительно за **зефир**. Кофе **не требуется ни для одной новой покупки здания**; он по-прежнему используется для ускорений строительства. Цена дорог и покупки земли **не меняется**.
- У **24** объектов введён минимальный достигнутый уровень города (2–5). У остальных минимальный уровень — 1.
- Требование уровня строго проверяется в общем движке `addObject()`, используемом серверным Worker; подмена запроса не позволяет купить закрытую постройку.
- Уже купленные объекты, существующие сохранения, перемещение, склад, возврат со склада и достигнутые уровни сохраняются. Блокировка относится только к **новой покупке**.
- В «Все» сперва открытые по уровню, затем закрытые. Внутри групп приоритет основным зданиям, затем цена. Категории остаются.
- Карточки показывают размер, время стройки, стоимость с иконками валют, бонусы жителей и уюта, метку `🔒 Ур. N` и сообщение о недостающих валютах. Закрытые карточки не начинают покупку: нажатие показывает условие открытия. Не создаются дополнительные всплывающие экраны поверх карты.
- Сортировка обновляется при изменении уровня, но **не** при каждом изменении кошелька, чтобы карточки не прыгали во время просмотра.

Награды за уже достигнутые уровни города в этом патче не изменены. Изменение их суммы потребовало бы отдельного решения о компенсации игрокам, которые уже забрали награды.

## Архив и порядок применения

В ZIP находится **установщик**, а не полная замена `world/app.js`, `world/engine.js`, CSS и тестов. Он проверяет совместимость всех **18** затрагиваемых файлов до записи; при несовпадении хотя бы одного фрагмента ничего не применяет. Установка одноразовая: не запускать второй раз после успешного применения.

Файлы архива:

- `scripts/apply-world-shop-v17.py` — проверяемый установщик, `--check` без изменений.
- `scripts/check-world-shop-v17.mjs` — базовые проверки экономики/UI и авторитетности Worker.
- `world/tests/shop-progression-v17.test.mjs` — 8 новых игровых тестов.
- `README_MIR_ZEFFI_SHOP_PROGRESSION_V17_RU.md` — эта инструкция.

Установщик изменяет: `world/economy.js`, `world/catalog.js`, `world/engine.js`, `world/app.js`, `world/ru.js`, `world/premium-ui.css`, 11 существующих `world/tests/*.test.mjs` и `scripts/check-zeffi-world-integration.mjs`. Изменения тестов — только согласование тестовых городов с ограничением по уровню и ценами, без обхода защиты в рабочем коде.

### В корне проекта `zefirok-run`

ZIP скачай в `~/Downloads/` (путь для macOS):

```bash
git status --short
git switch main
git pull --ff-only origin main

unzip -o "$HOME/Downloads/Mir_Zeffi_Shop_Economy_Progression_v17_patch.zip" -d .

python3 scripts/apply-world-shop-v17.py --check
python3 scripts/apply-world-shop-v17.py

node --check world/economy.js
node --check world/catalog.js
node --check world/engine.js
node --check world/app.js
node --check world/ru.js

node scripts/check-world-shop-v17.mjs
node --test world/tests/*.test.mjs
node --no-warnings --experimental-sqlite scripts/check-zeffi-world-integration.mjs
node scripts/check-world-new-city-pack.mjs
node scripts/check-world-api-wiring.mjs
node scripts/check-production-gate.mjs

git diff --check
git diff --stat
git status --short
```

**Если `--check` отказывает либо какой-либо тест падает, ничего не публиковать.** Это значит, что локальные файлы расходятся с проверенной версией, или есть другой конфликт. Не заменяй файлы вручную старой версией.

### После успешных проверок

```bash
git add world/economy.js world/catalog.js world/engine.js world/app.js \
  world/ru.js world/premium-ui.css world/tests/ \
  scripts/check-zeffi-world-integration.mjs \
  scripts/apply-world-shop-v17.py scripts/check-world-shop-v17.mjs \
  README_MIR_ZEFFI_SHOP_PROGRESSION_V17_RU.md

git diff --cached --check
git diff --cached --stat
git commit -m "balance(world): shop prices and city-level unlocks"
git push origin main
./update.sh
```

`git add world/tests/` добавляет только тестовые файлы из этой папки, но **перед коммитом обязательно проверь** `git diff --cached --stat` и `git status --short`, особенно при наличии других локальных изменений.

**Не вызывай прямой `wrangler deploy`.** Production обновляется штатным `./update.sh` после `git push origin main`.

## Автономная версия для тестирования

`Mir_Zeffi_Shop_Balance_Progression_v17_OFFLINE.html` — отдельный файл с встроенными WebP, **локальными тестовыми балансами** и тем же UI/прайсом. Открой в обычном Chrome/Safari на компьютере. Изменения в нём никак не влияют на реальный кошелёк или D1. Можно проверить замки, покупки, прогрессию города и каталог. Не замещай этим HTML production-файлы.

### Проверки, выполненные при подготовке

- **56/56** выбранных игровых unit-тестов (в реконструированной совместимой тестовой копии).
- **21/21** локальных D1-сценариев с Worker (в реконструированной тестовой копии; включает отказ купить закрытый автовокзал без списания).
- Проверки каталога: 48 карточек, уровень 1 и 5, блокировка по уровню, отсутствие JS-ошибок — в **облегчённой мобильной браузерной сцене**, не в полной игре.
- Полная автономная HTML-сборка подготовлена, но **её браузерный прогон в данной среде не завершился** из-за ограничений открытия локальных файлов и тяжёлой страницы. Полный production gate и реальный Telegram на iPhone здесь **не запускались**. Выполни вышеуказанные проверки и тест в Telegram перед открытием обновления широкой аудитории.

### После публикации тестировщикам

1. Город ур.1: можно купить домик, киоск и площадку; престижные объекты видны, но при попытке покупки выдаётся причина отказа.
2. Ур.2–5: постепенно открываются объекты, в «Все» открытые идут раньше закрытых.
3. Не хватает очков/зефира: корректная подсказка без списания.
4. Возврат старого престижного объекта со склада и перенос — разрешены.
5. Запрос `place` от ур.1 напрямую на автовокзал — отказ без списания и записи операции.
6. Ускорение строительства за кофе, получение наград за уровни города, иконки категорий и расположение дорог/персонажей работают как раньше.
