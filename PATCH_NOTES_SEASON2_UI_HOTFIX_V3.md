# Сладкий Забег — Season 2 UI Hotfix v3

Кумулятивный патч поверх актуальной сборки `Game.zip`. Включает исправления v1/v2 и дополнительную правку горизонтальной дорожки наград по повторному тесту от 13.09.2026.

## Новое исправление v3 — дорожка наград больше не уезжает в пустоту

Причина бага была в искусственном правом spacer после колонки `50+ / ∞`, который был добавлен для её визуального центрирования. Этот spacer становился реальной частью горизонтально прокручиваемого контента, поэтому на iOS дорожку можно было увести вправо и оставить большую пустую область.

Исправлено:
- правый spacer полностью удалён из reward track;
- программный переход к уровню теперь ограничивается реальным диапазоном `0..scrollWidth-clientWidth`;
- текущий `scrollLeft` принудительно нормализуется после рендера, изменения размеров и окончания touch-жеста;
- добавлена защита от iOS/WebView rubber-band по горизонтали: при попытке тянуть дальше первого/последнего элемента внешний пустой участок не открывается;
- вертикальный скролл страницы при этом не блокируется: edge-guard срабатывает только на явно горизонтальном жесте;
- `50+ / ∞` теперь останавливается у реального конца дорожки, без искусственной пустоты справа.
