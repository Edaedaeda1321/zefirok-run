Сладкий Забег — исправление потерянных Live Content ассетов
База: актуальный main на момент проверки, commit 554d3c92e6b5ad9d360a6e6ed754c99e3999c356.

Что исправлено:
1. Для встроенной косметики канонический путь к картинке из кода теперь имеет приоритет над устаревшим image_url из D1.
2. liveops_content_items автоматически синхронизирует устаревшие image_url с каноническими путями при первом чтении LiveOps после deploy.
3. Старые seasonal-case rows и снимки выдачи отображают/возвращают каноническую картинку косметики, даже если в D1 остался старый путь.
4. Добавлена build-проверка скрытых/сезонных ассетов. Она извлекает /assets/... из FUTURE_SEASON_CONTENT, LIVEOPS_CONTENT_IMAGES и системного S3 seasonal-case preset и останавливает deploy, если файл физически отсутствует в deploy input.
5. Release Gate не ослабляется: если файл реально отсутствует в опубликованном Cloudflare ASSETS, CRITICAL остаётся правильным.

ВАЖНО ПОСЛЕ MERGE:
Нужен полный deploy из корня репозитория командой `npx wrangler deploy` (или эквивалентный Cloudflare Git deploy, который использует wrangler.jsonc и assets.directory='.'). Worker-only upload не восстановит MP3/PNG в Cloudflare Static Assets.
