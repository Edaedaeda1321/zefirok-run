# Мир Зеффи — New City Pack v10 (production patch + автономный HTML)

## Что сделано

По переданному архиву `Mir_Zeffi_Premium_Individual_Sprites_v3_Fixed(1).zip` добавлено **7 новых объектов / 112 WebP**. Это весь доступный набор в исходном архиве, не ранее задуманные 17 объектов.

Каждый объект имеет 4 изображения завершённой постройки и 12 изображений строительства (3 стадии × 4 ракурса). **PNG из исходного архива не используются, не публикуются и в патч не входят**.

**Цены существующих объектов в текущем GitHub main не меняются.** На момент подготовки патча в main всё ещё были старые значения; ранее обсуждавшийся ценовой патч v7 не был найден в опубликованном main. Новые цены ориентированы на согласованную идею, что простые постройки требуют нескольких обычных забегов. Кофе/зефир остаются самостоятельными условиями покупки.

## Размещение и игровой цикл

- Новая категория **«Транспорт»** и русские названия/описания.
- Вращение, установка, хранение, восстановление, оплата, сохранение города и защита от двойного списания — через существующие `CATALOG` / `engine.js` / Worker и D1.
- Вокзал и остановка требуют соседнего подключённого Road для населения; в противном случае строить можно, но жители от транспортного объекта не начисляются, пока Road не проведён.
- Парк с прудом +2 жителя/+24 уюта; розарий +2/+20; ботанический сад +3/+32; спортивная площадка +1/+14. Бонус населения от одного вида этих новых парков даётся только первым двум завершённым экземплярам. Городская площадь даёт +12 уюта; вокзал +3 жителя/+15 уюта (с Road), остановка +1/+5 (с Road).
- В строительстве используются три **подлинных отдельных WebP из архива**, они автоматически меняются по времени. Ускорение за кофе использует существующий механизм: транспорт 70 кофе на старте, парки/площадки 50 кофе на старте, затем штатная скидка.
- Новые картинки в `world/assets/new_city_pack/<object>/webp/`. Старые картинки/здания не тронуты.
- `world/assets/manifest.json` и `world/sprite-manifest.js` синхронизированы: теперь 361 WebP, включая 112 новых. `world/assets/new_city_pack/calibration.json` содержит параметры посадки каждого из 112 спрайтов.

## Важный нюанс исходных изображений

Автор исходного пакета отметил **непроверенную геометрию** (у спрайтов из иллюстративных 2D-листов нет оригинального 3D world-origin) и возможную обрезку некоторых внешних краёв, особенно у `bus_terminal`, `pond_park`, `botanical_garden`, `sports_playground`. Один фрагмент `pond_park/build_03/n` мог быть потерян на уровне исходного листа. Их **невозможно полностью исправить точкой привязки**. Изображения оставлены без перерисовки в предоставленном виде.

В этом патче **точки опоры вычислены по нижней видимой ромбовидной основе WebP и размерам клетки 72×36** для каждого ракурса и стадии, а не просто записаны случайные значения. Это устраняет основной источник визуального «парения», но **финальное подтверждение всех ракурсов на настоящем iPhone Telegram требуется**. При обнаружении обрезанной части лучше заменить конкретный WebP, а не менять игровую экономику или мировые координаты.

## Два результата

1. `Mir_Zeffi_New_City_7_Buildings_v10_patch.zip` — только необходимые изменения для текущей main-ветки, 112 WebP, тесты, README. Не содержит PNG.
2. `Mir_Zeffi_New_City_v10_OFFLINE.html` — автономный браузерный файл с игровым Canvas/магазином/строительством/размещением, 361 встроенным WebP (112 новых + 249 старых), без серверных запросов. Тестовый кошелёк **800 000 очков, 6 000 кофе, 12 000 зефира** задан ТОЛЬКО в сгенерированном HTML. Файл открывается в браузере без сервера. Тестировать с пустым профилем браузера, чтобы старые локальные сохранения не подменили стартовый тестовый баланс.

## Установка в GitHub и обновление production

Поместить ZIP в корень `zefirok-run`, затем:

```bash
git status
git switch main
git pull --ff-only origin main
unzip -o Mir_Zeffi_New_City_7_Buildings_v10_patch.zip -d .
node scripts/check-world-new-city-pack.mjs
node --test world/tests/*.test.mjs
node --experimental-sqlite scripts/check-zeffi-world-integration.mjs
node scripts/check-world-api-wiring.mjs
git diff --check
git add world/catalog.js world/economy.js world/ru.js world/engine.js world/app.js \
  world/sprite-assets.js world/sprite-manifest.js world/assets/manifest.json \
  world/assets/new_city_pack/ world/build-standalone.py world/tests/ \
  scripts/check-world-new-city-pack.mjs scripts/check-world-integration.mjs \
  scripts/check-zeffi-world-integration.mjs README_MIR_ZEFFI_NEW_CITY_v10_RU.md
git diff --cached --check
git commit -m "feat(world): add seven premium city buildings with construction stages"
git push origin main
./update.sh
```

**Если любой тест упал — не делать `git push` и `./update.sh`.** Ни прямого Wrangler-deploy, ни D1-миграции для этого набора не требуется.

## Полезно для тестировщика

Открой автономный HTML в Chrome/Safari, нажми «Начать», открой магазин, выбери «Транспорт», «Парки» либо «Площадки». Пройдись по объектам, поверни каждый 4 раза, купи, дождись смены стадий или ускорь (в тестовом режиме). Проверь размещение рядом с дорогой, сохранение, перемещение на склад/из склада и отображение в разных масштабах карты.

*Формат автономного файла — реальная игра с встроенными WebP, не статическая галерея.*
