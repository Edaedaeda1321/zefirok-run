# «Сладкий Забег» — обновлённый «Сад встреч» (World Zeffi) · 16.10.2026

## Назначение

Компактное production-ориентированное обновление существующего `Edaedaeda1321/zefirok-run/main`, не новая игра и не автономный прототип. ZIP содержит **только изменённые и новые файлы**, с сохранением путей репозитория. `profile.html` не менялся.

**Изображения не создавались и не перерисовывались.** Использованы 10 стадий WebP из приложенного `Sad_Vstrech_10_stadiy_WEBP(1).zip`. Для производительности последние кадры дополнительно перепакованы в WebP с сохранением исходных размеров 1254×1254, прозрачности, композиции и ракурса. Кадры остаются разными файлами и загружаются по мере надобности.

## 1. Общий сюжетный город

- Одна общегородская площадка `Сад встреч` на карте 48×48: **x=11..16, y=40..45, размер 6×6** (начальная клетка 11,40).
- Замкнутый прогулочный обход проходит ПО СОСЕДНИМ клеткам: x=10 и x=17 при y=39..46, южная аллея y=46 при x=10..17. Северная часть соединена с существующей дорожкой y=39. Ни одна дорожка не проведена под зданием.
- Вне контура дорожек добавлены цветники, небольшие деревья, скамейки и фонари там, где свободна карта.
- Проверена геометрия соседних объектов, дорожек и автобусных маршрутов по всем проверяемым главам и стадиям; прежняя инфраструктура сохранена.
- Стадии строительства: `story-meeting-garden-01` … `story-meeting-garden-10`, из исходных файлов. Общий прогресс берётся из **действующего авторитетного D1-фонда `garden`**, а не из локальной случайной логики. При сборе средств показываются стадии 1–9, после завершения фонда — 10.
- **Взносы в общий Сад встреч остаются включёнными по старым правилам**. Все накопленные взносы/история сохраняются. В отличие от ранее внедрённого «Дворца воспоминаний», новый общий сад НЕ отключает донаты.

## 2. Личный город игрока — только за Элитный пропуск

- Отдельный вид объекта: `meeting-garden-pass` (**парк**, не декор и не здание). Он НЕ появляется в обычном магазине и НЕ доступен в типе наград `world_decor`.
- В CC → Сезонный пропуск → изменить награду появился тип **«🌳 Сад встреч · Элитный пропуск»**. Устанавливается только в **Элитную (premium) линию**, ровно по 1 штуке. Тариф Elite+ использует существующую доступность premium-линии.
- В базе сохраняется **постоянное право владения**, независимо от завершения сезона и выбранного оформления. `INSERT OR IGNORE` предотвращает повторную выдачу одному игроку.
- Только после честного получения награды в пропуске в складе «Мира Зеффи» появляется карточка парка. Первое размещение проверяется сервером через существующий `place-pass-garden`; D1 подтверждает владение в **одной транзакции** с сохранением города.
- Лимит **1 парк на игрока**, габариты **6×6**, бесплатная установка после получения награды, время стройки **6 часов**. Поворот и ускорение кофе запрещены (включая серверный API); перемещение и возвращение со склада сохраняют владение.
- Все 10 кадров строительного процесса привязаны к действующему серверному таймеру, от первого этапа до готового парка.
- Предусмотрена защита уже выданных наград: CC не разрешит назначить парк поверх ранее полученного игроками уровня в текущем сезоне. Для запуска лучше выбирать ещё никем не полученный уровень или следующий сезон.

## 4. Команды установки на Mac

Убедитесь, что рабочая копия на ветке `main` актуальна, а незакоммиченных посторонних правок нет:

```bash
git status
git branch --show-current
git pull --ff-only origin main
unzip -o ~/Downloads/Sladkiy_Zabeg_Sad_Vstrech_Elite_Pass_Patch_2026-10-16.zip -d .
git diff --check
npm run check:fast
node --no-warnings --experimental-sqlite --test world/tests/meeting-garden-v1.test.mjs
npx --yes wrangler@4.131.1 d1 migrations apply zefirok-rewards --remote
git status
git add -A
git commit -m "Add Meeting Garden stages and Elite Pass park"
git push origin main
./update.sh
```

**Не запускать** `npx wrangler deploy` отдельно: `./update.sh` — штатный production-flow этого проекта.
