# Мир Зеффи v0.1.11 — Coffee Skip + Magic Build FX

## Обновление ускорения строительства

- Здания (`homes`/`shops`): **70 кофе** при старте.
- Парки, фонтаны и строящийся декор: **50 кофе** при старте.
- Каждая полная прошедшая минута снижает цену на **25 кофе**.
- Минимальная стоимость ускорения незавершённой стройки: **5 кофе**.
- Очки и зефир при ускорении НЕ списываются. Стоимость здания/парка при покупке не изменена.
- Цена вычисляется по сохранённым `buildStartedAt` и `buildReadyAt` в `engine.js`; после перезапуска не сбрасывается.
- Кнопка и диалог показывают актуальную цену и следующий момент удешевления.
- При подтверждении модель сразу списывает кофе и завершает постройку, сохраняя город **до** анимации. При закрытии окна платёж и постройка не теряются.
- Визуальное ускорение занимает около 2.55 сек: три WebP-стадии стройки, затем анимированное появление готового объекта со свечением и золотистыми искрами.
- Запуск анимации: отдельный цикл `requestAnimationFrame` с перерисовкой ~30 FPS. Стадии и финальная модель заранее подгружаются перед оплатой, если доступно.

## Совместимость и безопасность

Рабочая основа — v0.1.10 с No-Round Terrain v0.1.9. ID построек, карты, дороги, расширение земли, цены объектов, таймеры и сохранения без изменений. Только WebP. Тестовая локальная экономика: Worker, D1 и production не затронуты.

## Запуск и тестирование

Для просмотра: распакуйте ZIP и откройте `index.html` в его корне. Это автономная HTML-сборка.
Для исходников: `world-v01/index.html` через локальный HTTP-сервер (например, `python3 -m http.server 8080`).
Тесты: `cd world-v01 && npm test`.
Пересборка автономного запуска: `cd world-v01 && python3 build-standalone.py`, затем скопировать `../world-v01-preview.html` в `../index.html` и `../ЗАПУСТИТЬ_ИГРУ.html`.

# Мир Зеффи v0.1.9 — No-Round Terrain

Сборка на основе v0.1.8 Terrain Rollback, с полностью новой землёй из `Mir_Zeffi_Premium_Terrain_No_Round_Pack_v1` (`Архив.zip`).

## Что добавлено
- 9 новых видов земли: чистая трава, полевые цветы, камни, луг, садовая почва, декоративная мозаика, песчаный участок, цветочный край, кустарники.
- Оригинальные 3D-спрайты подрезаны **только до верхней поверхности** в WebP и приведены к одной изометрической сетке 72x36. Это необходимо: в исходном наборе все 9 тайлов имеют собственные земляные боковины; их повторение на каждой клетке делало бы карту сеткой кубиков. Боковины теперь рисуются только на внешних краях общей земли.
- Текстуры на пустых клетках выбираются детерминированно по координатам: карта не меняется случайно при перезапуске.
- При размещении здания, декора, Road или площади травяное покрытие под их клетками становится `terrain_grass_clean_premium`; при переносе постройки исходная декоративная поверхность возвращается автоматически.
- 8 новых 1x1 модулей в каталоге **Ландшафт**: платформа, бордюр, прямые края, внешние/внутренние углы, ступени, подиум. Это декоративные конструкции, а не изменение высоты ячеек игрового движка.
- 2 новых цветных WebP-подсветки (выбор и расширение территории).
- Сохранены старые 12 предметов ландшафта v0.1.7 в каталоге как **retired**, только чтобы уже купленные постройки не исчезали из локальных сохранений. Их нельзя купить заново.

## Что не менялось
- Действующая тестовая экономика и цена Road (50 очков за новую клетку).
- Цена расширения участков 4x4 увеличивается после каждой покупки: x1, x2, x4, x8 и т.д.
- Таймеры зданий, парков и пропуск строительства.
- Конструкция и размещение объектов, сохраняющиеся ID зданий, склад, вращения, road connectivity.
- Никакой интеграции в production, Worker или D1.

## Запуск
1. Распаковать ZIP целиком.
2. Открыть `index.html` или `ЗАПУСТИТЬ_ИГРУ.html` в корне двойным кликом. Это автономный HTML со встроенной WebP-графикой.
3. Для стабильных сохранений по локальному адресу при наличии Python 3 можно использовать `START_MAC.command`, `START_WINDOWS.bat` или `python3 START_SERVER.py`.
4. Исходники находятся в `world-v01/`. Запуск через сервер: `cd world-v01 && python3 -m http.server 8080`.

## Проверки

- Проверьте дополнительно визуально стыки и читаемость на телефоне: автоматические тесты не заменяют художественную приёмку.
