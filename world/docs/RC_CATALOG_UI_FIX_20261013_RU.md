# «Мир Зеффи» — RC: каталог строительства и запрет выделения текста

**Основа:** предоставленный актуальный `Архив(20261013-104555).zip` с учётом подготовленных ранее патчей закрытого RC и исправлений рейтинга v2. Патч предназначен для последовательно обновляемой сборки, а не для замены произвольных устаревших файлов `world.html`.

## Исправленные проблемы

1. При долгом нажатии на игровой экран в iOS WebView можно было выделять текст. В `world/premium-ui.css` и `world/story/style.css` добавлен запрет `user-select`, `-webkit-user-select`, `-webkit-touch-callout` для игровых экранов. Обычные поля ввода (input/textarea/contenteditable) исключены из запрета.
2. Требуемый уровень здания появлялся только под ценой и мог обрезаться. Все 49 карточек теперь получают хорошо видимую плашку `С ур. N` на самой миниатюре. У закрытых построек сохранён замок; надпись ниже цены сокращена. Источник уровня — **тот же `CATALOG.minCityLevel`**, который проверяется серверной системой. «Белый Кролик · кафе „Зефирок“» открывается с 5-го уровня.
3. Удалена строка «Покупки подтверждаются сервером» внизу каталога. `panel-footer` исключён из обоих HTML-вариантов; освобождённая высота используется карточками и ценами. Невидимый `resetButton` оставлен исключительно для совместимости существующего обработчика, но не занимает место.
4. Подбор пропорций миниатюры и текста для узкого мобильного экрана исправляет обрезание цены и уровня.
5. Обновлены версии подключаемых файлов в опубликованных `world.html` и `story-world.html`, чтобы WebView не переиспользовал старый JS/CSS.

## Что не изменялось

- Авторизация Telegram, `WORLD_ENABLED`, `WORLD_TESTER_IDS`, белый список игроков.
- Данные игроков, D1-схема, Worker, кошельки, траты, награды, расчёт уровня.
- Покупки по-прежнему проходят через server-authoritative API.
- Новых миграций D1 **нет**.
