# Проверочный лист закрытого Release Candidate

- [ ] Сборка разворачивается через штатный `./update.sh` после `git push origin main`.
- [ ] Для владельца/тестера из allowlist открыт «Мой район» с серверным D1-состоянием; нет тестовой валюты и «песочницы».
- [ ] Старые постройки и купленные участки сохранены, город не обнуляется и не перезаписывается при сбоях.
- [ ] В «Общий город» можно перейти из личного района, а обратно — из общего. Никакие debug-панели не показываются.
- [ ] Тестёр может смотреть общий фонд, если сервер разрешает его чтение; проектное состояние соответствует D1.
- [ ] Неподписанный запрос и Telegram ID вне allowlist отклоняются на всех маршрутах; URL-флаги не дают доступ.
- [ ] Если `WORLD_ENABLED=false`, личный город, общий город и фонд недоступны; основная игра продолжает работать.
- [ ] Сбои сети, 401/403, 503 и неполное состояние не переводят город в браузерную локальную игру.
- [ ] Валюты личного города совпадают с основным кошельком; платные операции при включении разрешений списываются однократно.
- [ ] При отключённых `WORLD_PURCHASES_ENABLED` и `WORLD_COMMUNITY_CONTRIBUTIONS_ENABLED` реальные списания не проходят.
- [ ] Нет избыточных startup-запросов World при обычном входе в раннер без открытия режима.
- [ ] Production-gate и schema/asset проверки проходят; в статические ресурсы не публикуются папки тестов и исходный арт-пак.

До отмеченных проверок RC подготовлен локально, но НЕ считается проверенным на рабочем сервере Telegram/Cloudflare.
