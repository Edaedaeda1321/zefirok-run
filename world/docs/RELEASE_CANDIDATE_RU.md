# «Мир Зеффи» — Release Candidate (закрытый доступ)

Дата подготовки: 13.10.2026.
Основной источник кода: пользовательская сборка `Архив(20261013-104555).zip` (13.10.2026).
Изменения подготовлены для включения в существующую production Telegram Mini App «Сладкий Забег»; это **не** автономная игра и не новая БД.

## Что изменено

1. Внешние пользовательские названия приведены к «Мир Зеффи», «Мой район», «Общий город», «Ранний доступ». Убраны основные ярлыки «ТЕСТ», «ПЕСОЧНИЦА», «V1» и служебное меню из **опубликованных** экранов. Локальные средства разработки сохранены только для разработки.
2. Вход в личный город доступен только после POST `/api/world/state` с подписанной Telegram-сессией, наличием Telegram ID в `WORLD_TESTER_IDS` и ответа с `serverAuthoritative: true` и ревизией D1. Флаг URL `?world_tester=1` больше не требуется. При сбоях D1 никакого перехода в браузерную песочницу нет.
3. Серверный флаг `WORLD_ENABLED` теперь аварийно отключает **все** маршруты `/api/world/*`, включая `/api/world/story-access` и `/api/world/community/*`. Любой запрос без подписанной авторизации или вне списка допуска отклоняется до чтения кошелька и операций.
4. Система личного города сохраняет общую D1/кошелёк, серверную авторитетность, CAS-ревизии, idempotency и ограничения `WORLD_PURCHASES_ENABLED`. Ни цены, ни награды, ни существующие сохранения не сбрасываются.
5. Общий город остаётся на существующей визуальной сюжетной карте. Реальные общественные взносы при включённых разрешениях обрабатываются **только** серверным фондом D1. Клиентские демонстрационные сценарии нельзя включить через опубликованное меню; тестовое локальное состояние не сохраняется на hosted-входе.
6. `.assetsignore`: исходный отдельный арт-пак `Mir_Zeffi_Park_Belkino_4_Views_v1/` исключён из публикуемых статических файлов. Сам каталог в репозитории/локальной папке не удаляется.
7. Добавлен самостоятельный security/regression тест `scripts/check-world-rc-gate.mjs`, включён в production gate. Существующие тесты обновлены под закрытый RC (без URL-тестера и локальной песочницы).

## Что сознательно не изменено

- `profile.html`, действующие покупки основной игры, Battle Pass, кейсы, мини-профиль, рейтинги, D1-хранилище игроков и все `migrations/`.
- Telegram ID не записывались в код и не пересоздавались. Используется только **существующий** `WORLD_TESTER_IDS` из переменных окружения Cloudflare.
- Остались исходники автономной песочницы и тесты `world/tests/` для разработчиков, исключённые из публичного деплоя. Не следует удалять их до выделения отдельной development-сборки, потому что на них завязаны автоматические проверки.
- Имена внутреннего API `access: tester`, `mode: local-demo`, `story-v1` сохранены во избежание несовместимости с уже открытыми клиентами. В интерфейсе они больше не отображаются.
- Для общего города **ещё не добавлена серверная система сюжетных глав**. Сюжетная карта как визуальный слой остаётся ознакомительной; **только** фонд и личный район имеют настоящую серверную прогрессию. Это намеренное ограничение RC, а не обещание полного открытого релиза.

## Важные условия включения только для допущенных игроков

В Cloudflare Worker должны быть настроены:

| Переменная | Рекомендуемое условие | Что контролирует |
| --- | --- | --- |
| `WORLD_ENABLED` | `true` для RC | Вся система World API, включая общую карту и фонд; `false` закрывает всё |
| `WORLD_TESTER_IDS` | оставить существующие Telegram ID | Закрытый список, обязателен на каждом API-маршруте; пустой список закрывает всем |
| `WORLD_STORY_ENABLED` | `true` или не задана | Дополнительный выключатель общей карты/фонда |
| `WORLD_COMMUNITY_FUND_ENABLED` | `true` при наличии применённой 0115 | Чтение общего фонда |
| `WORLD_PURCHASES_ENABLED` | сохранить текущий флаг | Разрешение реальных платных операций в личном городе; их стоимость списывается с общих валют |
| `WORLD_COMMUNITY_CONTRIBUTIONS_ENABLED` | `false` на первом read-only smoke-тесте, затем по решению владельца | Реальные взносы в общий фонд, совместно с `WORLD_PURCHASES_ENABLED` |

**Не включать** `WORLD_ENABLED` с отключённым/некорректным allowlist и не добавлять обходов по имени пользователя, query-параметру, localStorage или initDataUnsafe.

Внимание: если `WORLD_ENABLED` **сейчас** не выставлен в `true`, после применения патча World закроется даже для разрешённых тестеров до включения этого флага. Нельзя обещать, что в текущем Cloudflare окружении он уже включён: в архиве значения не видны.

## Перед включением

- Убедиться, что удалённая D1 `zefirok-rewards` содержит выполненные миграции `0114_zeffi_world.sql` и `0115_zeffi_community_fund.sql` (новых миграций в патче нет). Не применять миграции вслепую, если список ожидающих содержит неизвестные изменения.
- Сверить рабочую копию с ZIP от 13.10.2026. Если файлы уже менялись позже, сначала сделать merge, не заменять их без проверки.
- Проверить значения `WORLD_ENABLED`, `WORLD_TESTER_IDS` и других флагов в **рабочем** окружении Cloudflare: этот архив не содержит удалённую конфигурацию или секреты.

## Применение на Mac

Сохранить ZIP в `~/Downloads` и перейти в реальный `zefirok-run`:

```bash
git status --short
unzip -o "$HOME/Downloads/Mir_Zeffi_Release_Candidate_closed_20261013.zip" -d .
node scripts/check-world-rc-gate.mjs
node scripts/check-production-gate.mjs --skip-d1
git diff --check
```

Проверить миграции D1:

```bash
npx --yes wrangler@4.131.1 d1 migrations list zefirok-rewards --remote
```

Если проверки пройдены, добавлять **только** файлы патча, без уже накопившихся в корне чужих папок и бэкапов:

```bash
git add -- .assetsignore index.html world.html story-world.html src/zeffi-world-service.js \
  world/app.js world/story/app.js world/story/boot.js world/story/entry.js \
  world/story/style.css world/story/map.js \
  scripts/check-world-premium-ui.mjs scripts/check-world-telegram-safe-area.mjs \
  scripts/check-world-dual-v1.mjs scripts/check-world-api-wiring.mjs \
  scripts/check-world-story-v1.mjs scripts/check-world-community-v1.mjs \
  scripts/check-world-rc-gate.mjs scripts/check-production-gate.mjs \
  world/tests/festival-hall-stages-v1.test.mjs world/tests/story-access-v1.test.mjs \
  world/docs/RELEASE_CANDIDATE_RU.md world/docs/QA_CHECKLIST_RU.md world/docs/CHANGED_FILES.txt
git diff --cached --check
git diff --cached --stat
git commit -m "Prepare Zeffi World closed release candidate"
git push origin main
./update.sh
```

Не запускать `git add -A`: оно добавит посторонний мусор из корня. Production-deploy исключительно через `./update.sh`, **не** прямой `npx wrangler deploy`.

## После деплоя / план smoke-проверки

1. Участник из существующего `WORLD_TESTER_IDS`: открывает «Мой район», видит данные из D1, может переключиться в «Общий город» и обратно. Перезагрузка не стирает серверные постройки.
2. Обычный игрок вне allowlist: видит заглушку, не получает данные или возможность списания по World API.
3. Игрок без подписанной Telegram-сессии: отказ в World API и отсутствие локальной песочницы.
4. При `WORLD_ENABLED=false` **все** пять World API закрыты. Проверять выключатель желательно до операций с реальными валютами.
5. При недоступной D1: игра не падает в локальный режим; нет двойных списаний, фальшивого кошелька и ложного сохранения.
6. Платные операции и пожертвования тестировать **только** после отдельного включения серверных флагов и понимания, что это реальные балансы.

## Откат

- Быстрый серверный отказ в доступе: `WORLD_ENABLED=false` в окружении Cloudflare (закроет и личный, и общий город, не удаляя сохранения).
- Кодовый откат: вернуть изменённые файлы по Git на предыдущее состояние; не выполнять `git reset --hard` без проверки локальной работы.
- Миграций и D1 data updates этот патч не производит; rollback D1 не требуется.
