# Мир Зеффи — RC: подсветка интерактивного обучения, шаг 3

Дата: 13 октября 2026 г.  Источник: актуальная main после внедрения обучения RC.

## Симптом

На шаге 3 «Найди жилые дома» каталог виден, но кнопка «Жильё» не подсвечивается, всё затемнено и игрок не понимает, куда нажать.

## Первопричина

`createWorldTutorial.show()` измерял координаты подсвеченной кнопки в первом `requestAnimationFrame`, сразу после раскрытия `#bottomPanel`. В этот момент CSS-анимация высоты панели ещё не закончилась: кнопка находилась за границей viewport, поэтому `layout()` оставлял `halo.hidden=true` и маски затемняли весь экран. После завершения `transition` координаты не обновлялись — resize или scroll при CSS transition не происходят.

Воспроизведено в браузере на мобильном viewport: в первом кадре `top=910 > innerHeight=896`, после перехода `top=623`, но `halo.hidden` оставался `true` до исправления.

## Исправление

- `world/tutorial.js`: пересчёт подсветки при `transitionend` **только если меняется целевой элемент или его родитель**; однократная резервная перепроверка через 340 мс для WebView с прерванными переходами; прокрутка целевого элемента лишь внутри горизонтального каталога/вкладок, без движения карты.
- `world/app.js`: на шаге 3 целевая вкладка «Жильё» докручивается в область видимости; свежий импорт исправленного tutorial.js.
- `world/story/app.js`: свежий импорт общего tutorial.js, чтобы улучшение применялось в Общем мире.
- `world.html`, `story-world.html`, `world/story/boot.js`: bump `rc-guide1` -> `rc-guide2` для гарантированной загрузки обновлённого JS/CSS в Telegram WebView.
- Проверки версий загрузчика, API и интерфейса обновлены, но не отключены.
- Новый regression-тест `world/tests/tutorial-spotlight-reflow.test.mjs` моделирует скрытую вкладку до конца transition, восстановление halo, нажатие и fallback без `transitionend`.

## Объём и безопасность

Нет изменений в `src/worker.js`, D1, схемах, миграциях, кошельке, наградах, зданиях или allowlist. Не создаются фоновые циклы и дополнительные API-запросы. Закрытый RC и `WORLD_TESTER_IDS` остаются как были.

## Результаты

- Браузер: до исправления halo остаётся скрытым; после исправления он появляется после перехода, пользовательский клик по «Жильё» проходит, следующий шаг отображается.
- Старый tutorial.js: обе новые регрессионные проверки падают; исправленный — обе проходят.
- 301 тест `world/tests/*.test.mjs` пройден.
- 71 production-gate проверка пройдена с `--skip-d1` (полное D1 интеграционное испытание не запускалось).
- Реальный Telegram iOS после деплоя потребует smoke-тест: шаг 3, шаг 4 и повторный вход на сохранённый шаг 3.
