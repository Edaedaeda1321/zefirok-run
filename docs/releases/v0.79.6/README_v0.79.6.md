# Zefirok Run v0.79.6 — плавность игрового процесса

Версия устанавливается поверх v0.79.5. Изменён только `index.html`.
Worker, D1, миграции, экономика, цены и игровые ассеты не изменялись.

## Что исправлено

### Фиксированный шаг игровой логики

Игровая логика теперь рассчитывается стабильными шагами `1/60` секунды, а `requestAnimationFrame` используется для вывода результата на экран.

Это убирает изменение размера шага при последовательности кадров вроде 16 → 17 → 33 → 16 мс. Старый цикл сохранён и включается одной настройкой.

За один экранный кадр выполняется не более пяти догоняющих шагов. После длинной остановки игра не пытается мгновенно просчитать десятки пропущенных кадров.

### Интерполяция изображения

Между двумя состояниями логики плавно интерполируются:

- препятствия;
- собираемые предметы;
- дорожная текстура;
- собачка и кадры её бега;
- обычные частицы и следы.

Столкновения при этом используют настоящие логические координаты, а не визуально сглаженные. Размеры хитбоксов не менялись.

### Тяжёлый античит перенесён за пределы активного забега

Периодическая полная сериализация прогресса больше не выполняется во время бега. Проверка откладывается и принудительно выполняется:

- при паузе;
- при сворачивании приложения;
- перед завершением забега;
- перед продолжением после паузы.

Защита прогресса не отключена.

### Кеширование масштабированных спрайтов

Часто рисуемые изображения один раз подготавливаются в нужном размере на вспомогательном canvas:

- собачка;
- препятствия;
- собираемые предметы;
- тени и повторяющиеся игровые изображения.

Кеш ограничен 48 элементами и автоматически очищается при изменении размера игрового canvas.

### Расширенные замеры кадра

Добавлены отдельные показатели:

- среднее и p95 полного кадра;
- среднее и p95 обновления логики;
- среднее и p95 отрисовки;
- максимальное время update и draw;
- количество фиксированных шагов;
- отброшенное время при чрезмерном догоняющем расчёте;
- число отложенных проверок античита;
- попадания и промахи кеша спрайтов.

## Флаги быстрого отката

```js
const CLIENT_OPT_FIXED_TIMESTEP = true;
const CLIENT_OPT_RENDER_INTERPOLATION = true;
const CLIENT_OPT_DEFER_HEAVY_ANTICHEAT_DURING_RUN = true;
const CLIENT_OPT_SCALED_SPRITE_CACHE = true;
```

Если на отдельном устройстве появится необычное отображение, сначала отключите `CLIENT_OPT_SCALED_SPRITE_CACHE`. Для полного возврата старого движения отключите `CLIENT_OPT_FIXED_TIMESTEP`.

## Что не менялось

Проверкой подтверждена неизменность следующих блоков относительно v0.79.5:

- `update(dt)` и все формулы изменения скорости и счёта;
- гравитация и сила прыжка;
- задержки появления препятствий и предметов;
- хитбокс собачки;
- проверка столкновений;
- все URL игровых ассетов;
- встроенный каталог Base64-изображений.

## Установка

Скачайте архив в `Downloads`. Выполняйте команду из корня `zefirok-run`:

```bash
ARCHIVE="$HOME/Downloads/zefirok-v0.79.6-gameplay-smoothness.zip" && \
TMP_DIR="$(mktemp -d)" && \
STAMP="$(date +%Y%m%d-%H%M%S)" && \
BACKUP_DIR="$HOME/zefirok-backups/v0.79.6-$STAMP" && \
mkdir -p "$BACKUP_DIR" && \
unzip -q "$ARCHIVE" -d "$TMP_DIR" && \
cp index.html "$BACKUP_DIR/index.html" && \
cp "$TMP_DIR/zefirok-v0.79.6-gameplay-smoothness/index.html" index.html && \
node scripts/check-assets.mjs && \
git diff --check -- index.html && \
npx wrangler deploy && \
rm -rf "$TMP_DIR" && \
printf 'Готово. Резервная копия: %s\n' "$BACKUP_DIR"
```

Миграции D1 применять не нужно.

## Проверка после deploy

1. Полностью закройте Telegram и снова откройте игру.
2. Проведите два забега длительностью хотя бы 20–30 секунд.
3. Посмотрите на движение подушки, вазы и пуфика относительно края экрана.
4. Проверьте прыжок на раннем и позднем этапе забега.
5. Соберите зефир и кофе.
6. Проверьте обычную паузу и сворачивание Telegram.
7. Убедитесь, что столкновение, очки и награды работают как раньше.

Показатели доступны в консоли внутреннего окна игры:

```js
window.__zefirokClientPerformance.snapshot()
```

Обратите внимание на:

```text
version: "0.79.6"
approximateFps
p95FrameMs
p95UpdateMs
p95DrawMs
fixedStepCatchUpDrops
fixedStepDroppedMs
antiCheatDeferred
spriteCacheHits
spriteCacheMisses
```

Для стабильного устройства желательно:

- `approximateFps` около частоты экрана;
- `p95FrameMs` около 16–20 мс на экране 60 Гц;
- `fixedStepCatchUpDrops` равен 0 или растёт очень редко;
- `fixedStepDroppedMs` равен 0 во время обычного забега;
- `spriteCacheHits` значительно больше `spriteCacheMisses`.

## Выполненные проверки

- синтаксис всех встроенных JavaScript-блоков через `node --check`;
- разбор внешнего и внутреннего HTML;
- разбор всех встроенных JSON-блоков;
- неизменность игровых формул и хитбоксов;
- неизменность списка URL ассетов;
- тестовый запуск в headless Chromium;
- начало забега и работа фиксированного шага;
- интерполяция включена;
- кеш спрайтов получает повторные попадания;
- тяжёлый античит откладывается во время забега;
- JavaScript-ошибок во время тестового запуска не обнаружено.

Headless-тест не заменяет проверку внутри Telegram WebView на реальном телефоне.
