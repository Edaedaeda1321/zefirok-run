📖 Сюжет сезона

Небольшие главы истории, которые открываются по уровню и при желании не раньше заданной даты.

События идут строго по порядку. Условие открытия: нужный уровень и, если указана дата, наступившая дата. Для открытия только по дате поставь уровень 1. Черновики можно безопасно проверить кнопкой «Тест себе».

↪ Перенос сюжета

Переносит главы в другой сезон без копирования прогресса игроков.

Страницы, картинки, музыка, награды, уровни и push сохраняются. Если у главы была дата открытия, она сдвинется на такое же расстояние от старта нового сезона. Главы, которые уже видели игроки, в старом сезоне не удаляются — они автоматически выключаются для сохранения истории.

🔥 Акции магазина

Flash Offer появляется только при входе игрока в магазин. Активную акцию можно редактировать, поставить на паузу, продлить или завершить раньше срока.

Покупка проверяется Worker’ом по ID акции: цена, состав набора, срок, сегмент и лимит не берутся из клиента. В одной акции можно объединять обычные награды, Элитный / Элитный+ и XP сезонного пропуска. Пустая картинка = автоматическая штатная картинка награды.

Новая акция

Сохраните черновик, проверьте предпросмотр и затем опубликуйте. Редактирование опубликованной акции применяется сразу.

Цена акции

Обычная цена · для зачёркивания и % скидки

Если в наборе есть пропуск, можно подставить его штатную цену текущего сезона.

Состав набора

Можно смешивать валюту, кейсы, физические товары, бусты, сезонный пропуск и XP пропуска.

Тариф пропуска можно объединить с XP и любыми другими наградами в одной акции. Если в набор добавлен Элитный или Элитный+, лимит автоматически фиксируется на 1 покупку для игрока. XP пропуска начисляется ровно в указанном количестве.

Картинка акции

Можно использовать стандартную, путь из проекта или свою картинку из Медиатеки.
