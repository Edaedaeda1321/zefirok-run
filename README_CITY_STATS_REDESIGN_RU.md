# Исправленный патч «Город в цифрах» V2 — 16.10.2026

Архив **полностью заменяет** предыдущий `Sladkiy_Zabeg_City_Stats_UI_Residents_Alerts_Patch_2026-10-16.zip`.
**Не нужно** повторно устанавливать предыдущий патч: здесь включены все его изменения и исправления.

## Почему `npm run check:fast` падал
После изменения количества видимых горожан тест `world/tests/resident-thoughts-rc4.test.mjs`
продолжал требовать одного прохожего в стартовом городе. Теперь это некорректное ожидание:
начальный город имеет двух жителей, и оба могут ходить по карте.

Исправлены связанные регрессионные тесты, не отключая их. Добавлен сценарий с четырьмя
персонажами: проверка количества, безопасных дорожек и разнесённых фаз движения.

## Что включено

- Большое окно «Город в цифрах» вместо мелкой раскрывающейся карточки:
  «Задания» (по умолчанию), «Книга развития», «Статистика».
- Перенесены действующие компоненты советов Зеффи, просьб жителей и городских глав.
- До четырёх жителей показываются все; далее работает плавно растущий лимит
  с верхней границей в 12 анимированных персонажей.
- Фазы движения по дорожкам разнесены, чтобы NPC не накладывались друг на друга.
- Красные ошибки отображаются 5,3 секунды и вынесены в верхний слой вне карты;
  их не могут обрезать шапка, строительная панель и игровой Canvas.
- Локальная песочница `world/index.html` согласована с тем же `world/app.js`.
- Никаких новых SQL-запросов, миграций D1 и изменений валют/серверных наград.

## Установка (из корня zefirok-run)

```bash
git status --short
git pull --ff-only origin main
unzip -o ~/Downloads/Sladkiy_Zabeg_City_Stats_Fix_V2_Tests_2026-10-16.zip -d .
node --test world/tests/citizens.test.mjs world/tests/resident-thoughts-rc4.test.mjs world/tests/citizen-footprint-occlusion-v15.test.mjs
npm run check:fast
git diff --check
```

Если проверки прошли и изменения не конфликтуют с другими незавершёнными работами:

```bash
git add world.html world/index.html world/app.js world/citizens.js world/engine.js world/premium-ui.css world/tests/citizens.test.mjs world/tests/resident-thoughts-rc4.test.mjs world/tests/citizen-footprint-occlusion-v15.test.mjs scripts/check-world-citizen-occlusion-v15.mjs
git commit -m "Fix Zeffi city stats overlay and resident visual regression"
git push origin main
./update.sh
```

**Важно:** пользовательские изменения `README_RU.md` и другие несвязанные неотслеживаемые
файлы из `git status` не нужно включать в этот коммит. Не используйте `git add -A`.
При сбое `./update.sh` прочитайте ошибку и не обходите защиту прямым деплоем.

## Проверка после деплоя

Откройте «Мой город» в Telegram и проверьте три вкладки, прокрутку карточек,
кнопки наград, закрытие окна, 2 NPC в стартовом городе / 4 NPC при четырёх
жителях, уведомления поверх интерфейса. Если дороги недоступны/заблокированы,
NPC, как и прежде, не создают запрещённые маршруты.
