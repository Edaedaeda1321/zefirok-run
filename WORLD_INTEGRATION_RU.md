# Мир Зеффи в «Сладком Забеге» — первый безопасный этап интеграции

Источник основной игры: приложенный `Zefirok_run.zip` (архив пользователя). Источник города: приложенный `Zeffi_World.zip` (v0.1.13, дороги восстановлены). В исходном архиве основной игры не было `.assetsignore`, `.gitignore` и `.github/workflows/production-gate.yml`; в **полной** объединённой копии они дополнены вариантами из актуального GitHub `main` только ради целостности локальной сборки/проверок. Существующий основной `index.html` не заменялся на отдельную игру и вложенный `data-srcdoc` сохранён побайтово.

## Что физически перенесено

- `world.html`: новая отдельная публичная HTML-точка входа в строительный режим. Работает только как **тестовая** песочница, с `?world_preview=1` или с локального хоста.
- `world/`: весь движок, CSS, каталог, модель города, 249 WebP, манифест, все 82 JS-теста, галерея ассетов, документация по Road и исходный `world/index.html`.
- `index.html`: только небольшой скрипт-кнопка на главном экране (в исходном iframe игры). Кнопка видна лишь в локальной среде или при `?world_preview=1`. Исходная игра не перезапускается при открытии/закрытии города.
- `world-preview.html`: автономный HTML с вшитыми WebP для просмотра без сервера. Это отдельный файл, не публикуемый Worker.
- `START_WORLD_TEST.py`, `.command`, `.bat`: локальный запуск двух режимов в одной сборке.
- `scripts/check-world-integration.mjs`: проверка целостности интеграции.

## Запуск

1. Распаковать весь ZIP в одну папку. **Не заменять отдельными файлами действующую production-сборку.**
2. На macOS: открыть `START_WORLD_TEST.command`, на Windows: `START_WORLD_TEST.bat`. Либо выполнить `python3 START_WORLD_TEST.py` из корня. Нужен Python 3.
3. Откроется `http://127.0.0.1:<порт>/index.html?world_preview=1`. В блоке «Игра» будет кнопка **«Мир Зеффи»** после «Задания».
4. Нажать кнопку — появится строительная карта поверх главной игры. Кнопка **«← В Сладкий Забег»** закрывает город, **не перезагружая раннер**.
5. Только градостроительную песочницу можно открыть двойным кликом по `world-preview.html`.
6. В тестовом браузере/стейджинге с доступом по HTTPS: `index.html?world_preview=1`, либо непосредственно `world.html?world_preview=1`.

## Безопасность

- Новых маршрутов Worker, миграций D1, реального кошелька, доступа к экономике игроков **нет**. Покупки и ускорения работают с тестовым локальным кошельком `localStorage`.
- Флаг `?world_preview=1` **не является серверной аутентификацией**. Поэтому нельзя считать режим готовым к публичному доступу и нельзя подключать реальные списания на этом этапе. Для следующего этапа нужна серверная проверка Telegram initData и флаг доступа только владельцу/тестерам.
- Папки с исходниками/тестами, автономный HTML и локальные launcher-файлы исключены из Cloudflare Assets через `.assetsignore`. Серверная точка `world.html` пока недоступна без тестового флага, а реальных покупок в ней нет.
- Старые цены, таймеры, парковка зданий, Road, склад, сохранения и анимация ускорения из приложенного World v0.1.13 не изменялись. Визуальные изменения графики на этой стадии не выполнялись.
- **Не выполнять `./update.sh` для этой сборки.** Deploy только после серверного access gate, D1 и согласованного production-флага.
